### [WARN] src/providers/registry.ts:~140 (withRouteNamedCredentialError) — Correctness / NFR-01

`if (decision.route === "CLI") return withRouteNamedCredentialError(new ClaudeCliCopyProvider())` also runs for a never-chosen team (no row in CLI mode, or a legacy `cli` row). For them the no-credential error is now rewritten to "Captions are set to the CLI route, but no Claude credential is available: ...". The team never set a route, so the text is misleading, and it breaks the byte-identical-errors rule (NFR-01; user decision). `generationErrors` still matches, so behaviour is intact and only the message differs.
**Fix:** wrap only when `decision.chosen`: `return decision.chosen ? withRouteNamedCredentialError(p) : p`.
