## Findings

### [NOTE] tests/e2e/a11y.test.ts:765-774, 951, 1214 — Dead code / stale wording

`const cliMode = (await register.innerText()).includes('image key')` can now never be true, because the button always reads "Register Provider". The comment `CLI mode hides COPY ("Image API key")` is false, and the CLI branch for 'Image API key' is unreachable. The test still passes in both modes, since the API labels now apply everywhere. Recommend updating it in this change (it is the change that removed the wording). Collapse to `getByRole('button', { name: 'Register Provider' })`, `keyLabel = 'API key'` and the single placeholder, and drop the `|Register image key` alternations at 766, 951 and 1214. Not a blocker: the current behaviour is green.

### [NOTE] src/lib/hooks/useCaptionRoute.ts:7 — Stale comment

The comment says "The card invalidates this key when it saves", but `CaptionRouteCard.tsx` calls `setQueryData`. Reword to "the card writes the PUT answer to this key".

### [NOTE] src/app/api/team/caption-route/route.ts:15-35 — Duplicate read

`stateFor` receives `setting` from a separate `team.findUnique`, while `loadCaptionRoute` reads `Team.captionRoute` again. A concurrent PUT between the two reads could return a `state` that disagrees with the route actually evaluated. This is a tiny window. If `RouteDecision` carries the setting, derive from it; otherwise accept it.

### [NOTE] src/app/(app)/team/page.tsx:~96 — CLI-mode register default

`useState<ProviderSlot>('COPY')` now also applies in CLI mode, where the old default was IMAGE. An admin pasting an OpenAI key there must flip the toggle; the amber hold text explains why Register is disabled. This is acceptable given the COPY slot is now visible. Mention it in the handoff if you want it intentional.

### [NOTE] src/components/brief/useBriefWizard.ts:372 — Route query failure

If GET caption-route errors after retries, `captionRouteLoaded` stays false, so `providersLoaded` is false forever. The warning is hidden, though Generate still works under the legacy gate. This fails soft and the server remains authoritative (422). Optionally use `isSuccess || isError`.

### [NOTE] tests/e2e/caption-route.test.ts (TC-ROUTE-09 comment) — Unasserted claim

The comment "the brief carries the row's key" for the never-chosen case is not asserted. AC-11's body-key check exists only for the chosen case. Low value; either assert the key is present or drop the comment.
