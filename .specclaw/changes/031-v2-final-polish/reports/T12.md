# T12 report: the brand-kit assistant fonts, the apply route, `previousFonts` in History

## Changes

- `src/lib/brandkit/assistant.ts`: the ```brandkit block `fonts` is the union (old `string[]`: entry 0 heading, entry 1 body; new `{ heading?, body? }`), default `{}`; optional `scriptFonts` record. `BrandKitSuggestion.fonts` is `BrandKitFonts`. The system prompt shows the new shape and asks for Google Fonts names only.
- `src/lib/brandkit/promptVersion.ts` (new): `createPromptVersion(tx, kitId, content, userId, previousFonts?)`, the version allocation extracted from `prompts/route.ts`.
- `src/app/api/admin/brandkits/[id]/prompts/route.ts`: POST uses `createPromptVersion` (behaviour unchanged, P2002 still 409). GET already returns every column, so `previousFonts` rides along.
- `src/app/api/admin/brandkits/[id]/assistant/apply/route.ts` (new): `withTeamAdmin`, kit team-checked (404 across teams). Strict zod body `{ voice?, colors?, fonts?: { heading?, body? }, scriptFonts? }`. Validates fonts through `validateKitFonts` (heading and body replace positions 0 and 1, the rest kept) and `validateScriptFonts`; any invalid part is a 400 and nothing is written. One `prisma.$transaction`: a new active prompt version when `voice` is given or fonts change (content defaults to the active version's content), with `previousFonts = { fonts, scriptFonts }` (the values before) only when fonts change; then `brandKit.update`. P2002 is 409. An empty body is a 400.
- `src/components/admin/brandkits/BrandKitAssistantPanel.tsx`: after a suggestion arrives, each proposed name (heading, body, Sinhala) is looked up through `/api/fonts?q=` keeping an exact match only. The accept view lists per font "Current: {x} → Proposed: {y}" or "{y} is not in the font list and won't be applied" (also "does not support Sinhala" for a family without the script), with the row's checkbox off and disabled. `apply()` calls only the new route. The button is "Apply to brand kit" and waits for the lookups (a fast click could otherwise skip the fonts; found by E2E). The W-16 promise text now holds.
- `src/components/admin/brandkits/PromptSection.tsx`: History shows "Fonts before this version: {heading}, {body}{, Sinhala: x}" on versions carrying `previousFonts` (`data-testid="previous-fonts"`).
- `src/lib/api-types.ts`: `BrandKitPrompt.previousFonts`.
- `src/lib/testHooks.ts`: the mock reply proposes `fonts: { heading: 'Playfair Display', body: 'Inter' }` and `scriptFonts: { sinhala: 'Noto Sans Sinhala' }`; the sentinel `__MOCK_FONT_UNKNOWN__` in the chat message swaps the body for the unknown name "Zzyzx Mock Sans".
- `docs/e2e-test-plan.md`: §AL completed (TC-AS-04 to TC-AS-06).
