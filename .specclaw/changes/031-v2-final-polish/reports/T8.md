# T8 report: the searchable font picker, the Sinhala picker, the snapshot date; the list of 100 deleted; §AJ

## Summary

- `FontEditor` searches `GET /api/fonts?q=` (React Query, key `['fonts', q]`, 200 ms debounce). Each result shows the family and a category tag; a delisted family also shows "No longer on Google Fonts". Saved chips read "Heading" (position 0) and "Body" (position 1). A new entry is sent with `url: ''`; the server computes the URL (FR-20).
- `ScriptFontPicker.tsx` (new): a `Select` labelled "Sinhala font" over `/api/fonts?script=sinhala`, "None (system font)" first. `KitDetail` saves `scriptFonts: { sinhala }` (null for None) in the same PATCH as name, colors and fonts. View mode lists the Sinhala font with a "Sinhala" tag.
- The kit GET returns `fontCatalogueDate`; the kit page shows "Font list from {date}".
- `src/components/admin/brandkits/googleFonts.ts` is deleted, and `uiTokenGuard.test.ts` no longer exempts it.
- `fontsBoundary.test.ts` is now an allow-list.
- E2E `post-fonts.test.ts` (§AJ), TC-PF-01 to TC-PF-08, and the §AJ section of `docs/e2e-test-plan.md`.
