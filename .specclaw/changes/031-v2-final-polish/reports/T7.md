## Tokenizer edge-case decisions (`inject.ts`)

**The HTML scan**

- It skips comments and `<!…>` / `<?…>` / end tags.
- It does not scan inside raw-text elements: `script`, `style`, `textarea`, `title`, `xmp`, `noscript`, `noembed`, `noframes`, `iframe`, `plaintext`.
- Closing tags are found with a case-insensitive regex from an index, never on a `toLowerCase()` copy (the Turkish `İ` length issue).
- An unclosed tag or attribute stops the scan. Nothing after that point is touched, and the link is still added.

**Attributes**

- Only quoted `style` values are rewritten; an unquoted value is left alone.
- Entity encoding: `&quot;`, `&#34;`, `&#x22;`, `&apos;`, `&#39;` and `&#x27;` are decoded. If any other `&` remains, the value is left untouched.
- After the rewrite, only the delimiter character is encoded back. A new name is quoted with the quote that is not the delimiter.

**The CSS scan**

- It skips `/* */` comments and strings. An unclosed comment or string leaves the whole CSS text unchanged.
- It tracks parentheses. A `:` at depth 0 starts a value, and the value runs to `;`, `}` or `{`. A `{` means the "declaration" was a selector or at-rule prelude (`a:hover {`).
- It keeps a block stack. A style sheet's declarations count only inside a rule, and never inside `@font-face`, whose `font-family` is a descriptor.

**The value rules**

- A value is extended only when every top-level item is a quoted string, an identifier sequence or `var(--x[, …])`.
- It is never extended when:
  - it is a lone `var()`;
  - it holds a CSS-wide keyword (`inherit` and the rest);
  - it holds a comment;
  - it holds any other function.
- `!important` is kept at the end.
- The family is inserted before a trailing unquoted generic keyword (serif, sans-serif, monospace, cursive, fantasy, system-ui, the four `ui-*`, emoji, math, fangsong); otherwise it is appended.
- A quoted `'serif'` is a family, not a generic.

**Custom properties**

- A name matching `/^--[\w-]*font[\w-]*$/i` is extended only when it does not also contain size, weight, style, stretch, variant, height, spacing, feature, kerning, synthesis, optical, palette, smooth, display, scale, colour, width, line, letter, transform, decoration, shadow, lh, leading or tracking.
- A single non-family keyword value (normal, bold, italic and the like) is never extended.

  This avoids breaking `--font-size: 16px` or `--font-weight: 700`, which the design's regex alone would have matched.

**Names, idempotence and the link**

- Quoting: a name is bare only when it matches `/^[A-Za-z][A-Za-z-]*$/` and is not a keyword. Otherwise it is quoted, which covers spaces and leading digits.
- Idempotence: the comparison strips quotes, collapses whitespace and ignores case. Edits are splices, so the rest of the document is byte-identical.
- The link:
  - every earlier marked link is removed, and one is inserted directly after the `<head>` start tag;
  - when there is no `<head>`, `<head>LINK</head>` is inserted after `<html>`, else after the doctype, else at the start;
  - the `href` is attribute-escaped (`&` becomes `&amp;`);
  - an empty plan (no families at all) returns the document unchanged, including any earlier link.

## Deviations from design §5.4 to §5.6

1. **The font check does not use `document.fonts.check()`** (§5.6). `check()` is false for a face that is declared but not needed by the post's text: faces load lazily, per unicode-range subset. It would therefore report a kit's Sinhala font, or its unused body font, as "did not load" on every English post. The rule used instead: a family is missing when `document.fonts` holds no face for it (its stylesheet was refused, blocked or never loaded), or when every face it holds is in `error`. The render suite proves both the missing cases and the no-false-positive case.
2. **The check runs on every real render**, not only when a headline is checked. Writers that do not stamp (the export, restore's re-render) ignore it.
3. **The refine route also injects into the rejected render and the conflict's `pendingHtml`.** Both can become stored design HTML through "Use anyway" or Override, and injection is idempotent. The Override commit itself does not call it.
4. **`MOCK_PUPPETEER` lets a sentinel-named family into the plan** (`plan.ts`). Without this, `__MOCK_FONT_MISSING__` could never reach the marked link, because FR-20 refuses non-catalogue names on save and `postFontPlan` skips them.
5. **AC-21 uses a synthetic font.** No small Sinhala font file that may be committed was available offline: Windows' Nirmala is a large, non-redistributable font collection. Nothing was downloaded. `tests/render/syntheticFont.ts` builds a minimal valid TrueType face in code, with one box glyph mapped from U+0D80 to U+0DFF; OTS accepts it. It proves which face painted the Sinhala code points, not how Sinhala looks.
6. **`renderedTextWriters.test.ts` was kept, and `renderStampWriters.test.ts` was added** (not a rename), so 030's guard and its docs references stay intact.
