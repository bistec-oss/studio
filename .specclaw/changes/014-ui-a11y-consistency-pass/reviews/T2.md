## Deviations

1. **StatusChip as two overloads, `status` last.** Sound. It keeps `ComponentProps<typeof StatusChip>['status']` as `PostStatus` for the existing `ScheduledQueueSection` typing, and it still rejects invalid prop combinations. It is a small departure from the design's union, and the comment explains why.
2. **Neutral Notice drops the `currentColor` ring and uses `rgb(var(--line))`.** Sound. `--line` is a space-separated RGB triplet in `globals.css`, so the value is valid. Two shadow utilities would otherwise be settled by CSS source order. No consumer yet.
3. **Test-only escaping and children-as-prop.** Fine.

## Findings

### [NOTE] src/components/ui/SectionHead.tsx:30 -- one row gap where the copies differ

**Problem:** The row uses `gap-y-2`, and the drafts copy uses `gap-y-1` (`drafts/SectionHead.tsx:18`). The campaigns copy uses `gap-y-2`. This only shows when the row wraps at 375 px, and it is the "four SectionHead rows" drift (D1, D2) the spec already accepts. It is not a defect, but T6 and T7 should expect a 4 px difference in the wrapped state in the capture diff.

### [NOTE] src/components/ui/SectionHead.tsx:36 -- `level={3}` drops `leading-tight`

**Problem:** `level={3}` uses `SUB_HEAD` (`leading-snug`), but the brand-kit `SectionHeader` that it replaces uses its own h3 string. The brand-kit migration task (T10 or later) should check the capture diff for that screen. Nothing to change in T2.

### [NOTE] src/components/ui/index.ts:15 -- `export * from './folio'`

**Problem:** This exposes the generic names `ICON` and `FOCUS` from the barrel. Every consumer that still has a local `FOCUS` or `ICON` must import them explicitly during migration, or it will shadow them. This is fine because it is the design's intent, but a name clash would be silent only when a file imports both. No change needed.

No BLOCK or WARN findings. The tests are meaningful: they assert the exact class strings, the element levels, the attributes, the absence of margins, and the unchanged `status` path. They would fail if any of those regressed.
