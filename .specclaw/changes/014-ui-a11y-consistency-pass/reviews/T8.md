### [NOTE] tests/unit/uiPrimitives.test.ts:42 — Test quality

**Problem:** The test was edited so that the default wrapper has no `min-w-0`. Nothing asserts that `actionsClassName` is applied to the wrapper, so the library's opt-in could be dropped without a unit failure.
**Suggestion:** Add one case: `PageHead({ title:'x', actions:<b/>, actionsClassName:'min-w-0' })` renders `class="flex flex-wrap items-center gap-2 min-w-0"`.

### [NOTE] tests/unit/uiTokenGuard.test.ts:34 — Guard false negatives

**Problem:** `SHARED_NAME` is anchored on `^\s*(export\s+)?(const|function)\s+NAME`. It misses `export default function PageHead`, `async function`, `let NAME` and `export const NAME: T = ...` after a type with a generic, and a rename in an import (`import { EYEBROW as E }`). None of these occur today, and the common regressions (`const X =` and `function X(`) are caught. The self-test samples cover positives, near-miss names, uses and the ui folder.
**Suggestion:** Optional. Change `(export\s+)?` to `(export\s+(default\s+)?)?(async\s+)?` and add a sample line.

### [NOTE] tests/unit/uiTokenGuard.test.ts:35 — Guard scope

**Problem:** `SMALL_CAPS_LITERAL` matches any text in a source line, including comments and strings. That is intended for FR-05, and the scan currently passes. It could flag a comment that quotes the literal, which would need rewording, because `ui-exception` is deliberately not honoured.
**Suggestion:** None needed. This is noted for awareness.
