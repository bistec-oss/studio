## Findings

### [NOTE] tests/unit/designTokens.test.ts (LITERAL regex) - false negative

`LITERAL` requires whitespace or a quote before the class, so a variant-prefixed literal (`md:h-10`, `hover:h-9`) is not caught. Grep shows none in `src/` today, so it is not a live miss. Suggestion: drop the leading anchor to `(?:^|[\s"'`:])`.

### [NOTE] tests/e2e/a11y.test.ts (AC-07)
