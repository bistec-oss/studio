## API

- **`folio.ts`** exports:
  - `FOCUS`, `SCROLL_FOCUS`;
  - `SMALL_CAPS` (no colour), `EYEBROW` (`SMALL_CAPS` + `text-fg-muted`);
  - `PAGE_TITLE` (no `mt-2`), `PAGE_LEAD`;
  - `SECTION_NUMERAL`, `SECTION_HEAD` (the h2 style), `SUB_HEAD` (+ `leading-snug text-fg`);
  - `NOTICE`, `ICON`, `ICON_SM`, `ICON_BUTTON`, `TEXT_LINK`, `TAG`, `TABLE_HEAD_ROW` and `COMPACT_FIELD`.

  A script compared every value with the existing local copies. All are identical except the two known drifts: brand kits' `SECTION_HEAD` is the h3 style, and drafts' `SUB_HEAD` has no `leading-snug text-fg`.

- **`PageHead({ eyebrow?, title, lead?, actions?, className? })`:** the root has no outer margin. The `h1` gets `mt-2` only when an eyebrow is present.
- **`PageTitle({ children, className? })`.**
- **`SectionHead({ title, numeral?, level = 2, id?, className?, children? })`:**
  - `level` 2 renders an `h2` with `SECTION_HEAD`; `level` 3 renders an `h3` with `SUB_HEAD`;
  - the numeral is `aria-hidden`;
  - the tail holds the children, `ml-auto`.
- **`Notice({ tone: warning|error|info|neutral, icon?, className?, children, ...HTMLAttributes })`:** no default role, and the ARIA and data attributes pass through.
- **`FieldLabel({ htmlFor?, id?, as = 'label', className?, children })`:** `${EYEBROW} block`.
- **`StatusChip`:** takes either `status` or `tone` with children. The `status` path renders the same classes as before, plus `flex-shrink-0 whitespace-nowrap`.

## Deviations from design §2

1. **StatusChip uses two function overloads, with `status` last.** A union parameter turns `ComponentProps<typeof StatusChip>['status']` into `PostStatus | undefined`, which breaks tsc at `ScheduledQueueSection.tsx:23/161`. The union prop shapes are kept, and a scratch tsc check confirmed the invalid combinations are rejected.
2. **The neutral Notice drops `NOTICE`'s `currentColor` ring.** Keeping it would put two shadow utilities on one element. Neutral has no consumer yet.
3. **Test-only:** children are passed as a prop in the `createElement` calls, and `'` is escaped as `&#x27;`.
