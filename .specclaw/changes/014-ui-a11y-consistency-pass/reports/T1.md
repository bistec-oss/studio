# 014 T1 report: the capture compare script and the `before` baseline

**Status:** built. One new file: `scripts/compare-captures.mjs`.

## The script

- **CLI:** `node scripts/compare-captures.mjs <before-dir> <after-dir> <diff-dir> [--expect <glob>...] [--noise <file>]`.
- **Comparison:** both images are decoded with sharp as raw RGBA and compared exactly, all 4 channels of every pixel.
  - A size mismatch is compared over the larger canvas.
  - A shot missing from `after` counts as differing.
- **Output:** a red-on-grey diff PNG per differing shot, a summary line `identical N, different M, total T`, and one line per differing shot tagged `[expected]`, `[noise]` or `[UNEXPECTED]`.
- **Exit 1** when any differing shot is neither expected nor noise, and when sharp won't load (with a clear message).
- **The noise file:** `design.md` §7 contradicts itself on its location (`<before>/../noise.txt` against `ui-captures/014-noise.txt`). The script defaults to the former and takes a `--noise` override. **The wave-1 gate passes `--noise ui-captures/014-noise.txt`.**
