## Judgement calls

1. **Stamp rect invariants and the size.** The stamp does not record the size, so the schema cannot know the canvas. The 16:10 and text-overlap rules hold when the rect satisfies them at one of the stamped contract's declared sizes (inside-canvas is size-independent). I did not add a `size` field, to keep the FR-06 shape; if you want the stricter check, add `size` to the entry in T8.
2. **`evaluateRegions` and a composite region.** It applies the invalid rule and then skips the region (no verdict), and `runHeroCheck` never passes one. I chose skip over fail-closed because the spec says "keep the region invalid handling" and the detector replaces the blank branch; the hero check is the only caller.
3. **`runHeroCheck` lives in `src/lib/renderer/heroCheck.ts`**, not in `background.ts`, so the tsx recheck can import it without pulling in prisma, the model layer or the provider registry.
4. **`sampleLuminanceGrid` has a fourth optional argument** `{ timeoutMs?, seamRegion? }`. `seamRegion` exists only so the `MOCK_PUPPETEER` synthetic grid can put its flat screen exactly on the contract region (the window cannot be inverted when it is clipped).
5. **Grid coordinates:** `x0, y0` are the position of the first sample point itself (the centre of the first 2 px step), because a smoothing-off `drawImage` samples the centre of each destination pixel.
6. **A transparent pixel is NaN** in the grid; NaN is never screen and never blank, so an image with holes fails closed.
7. **Text-overlap fixture:** the screen top is half a point inside the text band, because anything larger makes the text band itself fail busy/contrast first (the band test comes first, as in the app). The detector's `text-overlap` rule is also covered with a larger intrusion in `screenDetect.test.ts`.
8. **`probeVerdicts` still needs the user's verdicts:** a re-judged keep has `accepted: null`, so it is `pending` until a verdict is recorded with `--verdict`.
