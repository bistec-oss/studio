- **`KitDetail.tsx`:**
  - **Root:** a `<section aria-label={kit.name}>` under a 2 px rule. The kit name is an h2, and "System default" stays inside it, so the heading's name is unchanged.

  - **Colours:** hairline chips, each a data swatch plus its hex.
  - **Logos:** a contact-sheet grid; the primary has an ink frame and an accent label.
  - **Fonts, templates and artifacts:** ruled rows. The size options use `optionCls`, feed-to-AI is accent when on, and deletes are quiet icons.
- **`PromptSection.tsx`:** mirrors T10's briefing section. The active text is on a `.surface`, and history is a focusable labelled region of ruled rows.
- **`BrandKitAssistantPanel.tsx`:** mirrors T10's assistant:
  - **Documents:** ruled rows.
  - **Chat:** a ruled log, which becomes a labelled region once it has messages.
  - **Proposal:** a focusable region.
  - **Font guesses:** `TAG`s.
  - **Prompt:** an attached ink Send button.
- **`ColorEditor.tsx` / `FontEditor.tsx`:** hairline chips with focusable × buttons and token fields. The font listbox is `.surface-raised`.
- **`shared.tsx`:**
  - **`ColorSwatch`:** a `border-line` frame with a data fill.
  - **`SectionHeader`:** a numbered h3.
- **`AddKitModal.tsx`:** uses `Input`.
- **`googleFonts.ts`:** unchanged.

## The one `ui-exception` line

- **The line:** `shared.tsx:19`: `style={{ backgroundColor: color }} // ui-exception: brand-kit swatch, the kit's own colour from data`.
- **Where it renders:** this one component draws every kit swatch: the list rows, the palette, the colour editor and the assistant's proposed palette.
- **Logos:** shown as uploaded, with only their frames on tokens.
- **No font preview:** the kit fonts were never rendered in their own face, and adding that would load from `fonts.googleapis.com`, which the AC-19 no-CDN check forbids.
