### Review fix (WARN, orchestrator) and re-verification

The review's WARN was confirmed. The `animation-iteration-count: 1` cap froze `animate-spin` and `animate-pulse` under reduced motion, so loading states stopped signalling activity. Lifting the cap instead would have made them strobe at 1 ms per cycle.

**The fix:**

- **`globals.css`:** the reduced-motion block exempts `.animate-spin` (1.5 s) and `.animate-pulse` (2 s) and keeps them looping.
- **`designTokens.test.ts`:** it asserts the exemption, and its block regex no longer requires the block to end the file (the review's NOTE).
- **`DESIGN_SYSTEM.md` §7.3:** the snippet now matches the code: the cap plus the exemption, with the rule "a new looping loader uses one of these classes or adds its own exemption". This is an orchestrator doc sync outside T4's list.
