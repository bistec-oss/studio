## Notes for T11 to T13

- **sr-only cells in scroll containers:** an `sr-only` (absolute) element inside an `overflow-x-auto` container widens the page unless the container is `relative`. T12's tables should check for this.
- **Shared classes:** `campaigns/folio.ts` and `SectionHead.tsx` are the sixth copy. T13's shared primitive should absorb `CRUMB_*`, `ASIDE_*`, `TAG`, `ICON_BUTTON` and `COMPACT_FIELD` too.
- **Breadcrumbs:** the `CRUMB_LINK` + `nav` / `aria-current` pattern can serve detail pages in T11 and T12.
- **Primary on campaign detail:** "Plan a post" is Outline because the briefing's Save is the contextual primary. Making Plan a post the page primary instead is a one-word change.
