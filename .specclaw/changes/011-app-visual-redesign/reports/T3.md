## What T4–T6, T9 and T13 must know

- **T4, fonts:**
  - **Don't copy the `--font-*` lines literally.** `next/font` serves the files under generated family names. Use its `variable` option for `--font-display`, `--font-sans` and `--font-mono`, and its `fallback` option for the study's fallback stacks. Every other token copies as is.
  - **Fraunces needs `axes: ['opsz']`** and both styles. Without the axis, `font-variation-settings: "opsz"` is ignored silently.
  - **`tailwind.config.ts` `fontFamily.sans` points at `--font-inter` today.** Switching it changes the whole app's font at once, which conflicts with AC-08's "unmigrated screen renders unchanged". T4 must decide this explicitly.
- **T4, Tailwind clashes:**
  - **Spacing:** Folio's spacing equals Tailwind's default steps, so it needs no change.
  - **Radius:** Folio's `md` is 4 px and `lg` is 6 px, which doesn't match Tailwind's defaults by name. Add new keys and don't redefine `sm`/`md`/`lg` before T13.
  - **Font size:** `sm`, `base`, `xl` and `2xl` differ from Tailwind's. Add new keys, same rule.
  - **Status colours:** `status-*` maps both `DEFAULT` and `dark` onto the one var.
- **T4, AC-07 test.** Only colour, shadow and scrim tokens are in both `:root` and `.dark`. Radius, motion, type and spacing are in `:root` only.
- **T4, contrast test:**
  - Declare `line/*` at 3:1, and leave `line-subtle` out.
  - Chip alpha is 0.10 in both themes. Today's dark chips use 0.15, so T5's StatusChip must change that.
- **T5, reduced motion:** with 1 ms transitions on `*`, E2E checks (AC-17, AC-18) should wait briefly before reading computed styles.
- **T6, logo:**
  - `Logo.tsx` becomes the typeset "Studio" wordmark: Fraunces italic, 24 px, `-0.02em`, `opsz` 72, in the ink colour, with no `dark:invert`.
  - Its accessible name changes from "Bistec Studio" to "Studio". No test uses the old name.
  - Delete `public/BistecStudioLogo.png`.
- **T6, shell cleanup:** remove `.glow-blob` in `AppShell`, and make the sidebar nav text-only.
- **T9, draft page:**
  - **Folio's "More" menu would break tests.** The study moves Export and Edit inline into a More menu. But `tests/e2e/draft-inline-edit.test.ts` uses `getByRole('button', { name: 'Edit inline' })` in six cases, and a Radix menu item has the `menuitem` role.
  - **So** T9 keeps those controls as visible Folio-styled buttons, or moves into the menu only what changes no role or name (§8.17).
- **T13, the `ui-exception` guard:** match the substring `ui-exception:` on a line. In JSX children the marker is `{/* ui-exception: … */}` (§11).
