# T1 report: the pure rendered-text module

## What was built

`src/lib/renderedText/`, a pure module (zod, `HEADLINE_MAX`, the `Prisma` namespace only; no client, no I/O). Nothing imports it yet.

- `vocab.ts`: `HEADLINE_STATES`, `UNVERIFIED_REASONS`, `HEADLINE_CHECKS` (`as const`), their types, `HEADLINE_CHECK_TIMEOUT_MS = 5000`.
- `normalise.ts`: self-contained `normaliseHeadline` and `NORMALISE_HEADLINE_SOURCE`.
- `stamp.ts`: `renderedTextSchema` (discriminated on `verified`, `.strict()`), `RenderedText`, `parseRenderedText`, `renderedTextColumn`, `stampFromCheck`.
- `facts.ts`: `Rect`, `CandidateFacts`, `HeadlineFacts`, `HEADLINE_TOLERANCE_PX = 1`, `evaluateHeadlineFacts`.
- `mockCheck.ts`: `MOCK_HEADLINE_HIDDEN`, `mockHeadlineCheck`.
- `state.ts`: `headlineState`, `headlineImageFor`, `HeadlineImage`, `ScheduledPosts`.
- `noticeText.ts`: `headlineNoticeText(image)` returning `{ headline, reasonLine, scheduledLine } | null`, `publishLineFor(state)`, `formatScheduledDate`.
- `index.ts`: re-exports.
- `tests/unit/renderedText.test.ts`: 34 cases (AC-02, AC-05, AC-09, the normaliser rebuild on all listed strings, the stand-in, the notice text).

## Decisions

- **Date formatter:** `formatScheduledDate(iso)` prints `D Mon YYYY` in UTC from a fixed English month table (for example `3 Nov 2026`). No `Intl`, so server, browser and tests agree. An unparsable value is returned as given.
- `headlineNoticeText` returns null for `fresh` and `unknown` (the badge renders only for `stale` and `unconfirmed`).
- The normaliser's regex is `[\s   ]+` with escapes, not literal characters, so the source survives `toString()` and editors.
- The stand-in's "whole-text occurrence" is bounded by string ends or a space, as design 3.3 says. Because tags become spaces, "Big Launch Day" counts as one match for "Big Launch" (a word-boundary match, not a substring match). Documented by the test using "Big Launches" for the no-match case.
- `evaluateHeadlineFacts` takes an optional third `tolerance` argument (default 1), mirroring `evaluateCompositeFacts`.

## Deviations from the design

None of substance. `Rect` is defined in `facts.ts` rather than imported from `designData` (keeps the module free of that dependency).
