# T2 report: the in-page headline check and the mock stand-in

## What was built

- `renderPost(html, width, height, composites, check)` in `src/lib/renderer/puppeteer.ts`, returning `{ png, headlineCheck }`. `renderHtmlToPng` is now `(await renderPost(..., null)).png` with the same signature. Same `limit`, same composite pre-assert and composite mock sentinel order. Under `MOCK_PUPPETEER` it returns `MOCK_PNG_BUFFER` and `mockHeadlineCheck(html, headline)` (or null with no check).
- `withRenderedPage` gained an optional `beforeShot(page)`, run after `verifyComposite` and before `fn`. `renderPost` uses it for the check, so the facts and the PNG come from the same page. Existing callers pass nothing.
- In-page collector `collectHeadlineFacts` (one `page.evaluate`): rebuilds the normaliser from `NORMALISE_HEADLINE_SOURCE`, walks `document.body.querySelectorAll('*')` skipping script/style/template/noscript, keeps elements whose normalised `innerText` equals the headline, drops any kept element containing another kept one, and reports `visible` (`checkVisibility` with opacity and visibility), non-empty Range rects, clip boxes (self and ancestors up to body with non-visible overflow) and per-rect-centre `elementFromPoint` topmost. The verdict is T1's `evaluateHeadlineFacts`, in Node.
- `buildMockHtml(promptContext, w, h, headline?)`: with a headline adds `<div class="headline" data-mock-headline="true">{escaped}</div>` after the card; `__MOCK_HEADLINE_HIDDEN__` in the context adds a comment. Without both, output is byte-identical (existing exact-output tests pass unchanged).
- `buildMockRefineReply` default branch carries the `data-mock-headline` element from the current document into the reply; with none present the reply is unchanged. All sentinel branches untouched.
- T1 review additions in `tests/unit/renderedText.test.ts`: right/bottom canvas edge and clip-box tolerance cases (1 px passes, 1.5 px fails); explicit expected values for NBSP, U+2007, U+202F, NFD to NFC, and the Sinhala string.

## Test seam choice

`runHeadlineCheck(page: Pick<Page, 'evaluate'>, headline, canvas, timeoutMs = HEADLINE_CHECK_TIMEOUT_MS)` is exported. It wraps the collector in `Promise.race` against a timer; any throw or timeout returns `'not-checked'` and logs once as `[renderer] headline check: <message>`. A unit test hands it a stub page whose `evaluate` throws or hangs, with a small `timeoutMs`. No hooks object is needed, and the production call passes the shared 5000 ms bound.
