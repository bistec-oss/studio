## Ambiguities and choices

- `goal` in the payload schema is plain `.optional()`, not a default: the wizard never reads it; an old row parses and resumes as General.
- Resume computes touched-ness with no campaign loaded (campaigns load later); the worst case is a stored campaign-derived tone being treated as the user's own, which keeps the value the user saw.
- Changing a size to 9:16 or the path to A drops a hand-picked image style (as before: "resets"); going back re-follows the style.
- Clearing the campaign keeps the chosen style (spec silent).
- The Review always shows an Image style row (Classic on Path A / 9:16), so AC-06 can be read. A Path A Review is not E2E-reachable with the suite kit (no templates); it is covered by the resolver unit tests and TC-PS-31.
- Queue modal: editing a legacy (null key) entry shows "Not set"; saving without a change sends no key, so the stored null stays (T5 PATCH rule).
