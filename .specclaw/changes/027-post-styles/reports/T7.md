- `src/components/admin/insights/sections.tsx`, `src/app/(app)/admin/insights/page.tsx`: `PostStylesSection` (`InsightSection`, `DataTable`, `RateBar`; testids `section-post-styles`, `post-style-<key>`, `post-style-rate-<key>`), placed after Image styles. Super-admin gate unchanged.

## Choices

- "Chosen" counts `brief.submitted` (wizard briefs); queued entries have no such event, so they show under generations and held only.
- A key outside the dataset is emitted as null, so the validator never drops the whole event.
- Held counts `scheduled_generation.settled` with `held: true`.
- A mock caption puts each invented value in the headline and both captions, so two values give six flags (TC-OBS-31 asserts 6).
- Screenshots (`ui-captures/027/post-styles-{1440,390}-{light,dark}.png`, gitignored) were taken by TC-PS-40. At 390 px the page has no horizontal scroll (the table scrolls inside its region). The colour-scheme emulation did not visibly switch the app theme in the captures I viewed (the dark 390 shot looked light); the section was not checked in true dark beyond the axe pass.
