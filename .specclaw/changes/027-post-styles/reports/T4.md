## Ambiguities and choices

- **Version strings in existing assertions.** `prompts.test` (`PROMPT_VERSION` was `'2026-10-21.1'`, `CAPTION_PROMPT_VERSION` regex and `'2026-10-23.1'`), `generationUntouched.test` (`'2026-10-21.1'`, a 007 pin) and `heroPrompts.test` (the `^date.n$` regex) read a changed prompt-version string and were adapted to the derived value. The "one grep" test keeps passing unchanged because each base is still a quoted literal in its file. No E2E assertion read a version string; none was edited.
- **Sentinels on the headline.** FR-15 says the four value sentinels add a value to "the mock caption and headline text", design section 13 says "every caption". I followed FR-15: the four add their value to the headline and to both captions; `__MOCK_FACT_HEADLINE__` adds `$49` to the headline only. The value is appended after the headline cut, which leaves room for it inside `HEADLINE_MAX`.
- **Where the mock error seam lives.** The pure extractor must not import `testHooks`, so the seam is in the two prisma-side entry points (`computeFactsCheck`, `refreshFactsCheck`), inside their try, which stores `status: 'error'`.
- **Restore and adopt carry the draft's current stamp** (spec FR-05 list), not the revision's or the rejected row's own. Composition and model stay row-owned as before.
- **`postStyleColumn` on regenerate copy for an unstyled brief writes SQL NULL**, which equals what such a draft already holds.
- **Passing `undefined` for `db`** in the route's settle call (7th positional parameter). Chosen over an options bag to leave the six existing arguments and every other caller unchanged.
- **Facts check ordering on the sync path:** computed after `requireHeadline` and before the design call (cheap, and only needs the captions), written in the create after the design.
- **Cycle:** `captions/store.ts` imports `factsCheck/refresh.ts`, which imports `loadDraftCaptions` from the store. Both use the other only inside functions, so it is a benign import cycle. Noted, not "fixed".
- **Golden capture:** the strings were captured in a throwaway `git worktree` at the base commit `8816d89` (the builders are unmodified by T1 to T3, and `e283005` is the plan base) with `node_modules` junctioned, then the worktree and junction were removed (`git worktree list` shows only `D:/studio`). 16 cases: `buildBriefInput` (with and without kit), the caption system and user prompts, Path A (system and user, api and cli), Path B (system and user), the background decision (system and user), refine (cli and api). The 009 `heroPrompts` golden still passes unchanged.
- **NFR-01 count:** `git grep -c "createMessage\|runClaudeCli\|recordModelCall" -- src` is 77 lines-with-matches in total now and at `e283005`, file by file identical (`diff` empty). No call site added.
