# T6 — Generation on the resolver, with caption, headline and design stamps

**Status:** implemented, not committed (the orchestrator commits).

## Summary

- **Resolution at the generation's start.** `runGenerationForDraft` and `generateDraftForBrief` both call the new `resolveGenerationModels(brief, actor)` before anything else:
  - `CAPTION`, with `storedRequest: brief.captionModel`;
  - `DESIGN_TEMPLATE` or `DESIGN_FREEFORM` by `brief.designMode`, with `storedRequest: brief.designModel`;
  - on `brief.teamId`, as `actor.userId` (null for the scheduler, MCP and ACP, so the credential is always `team`).
  - A `NO_ALLOWED_MODEL` result throws `NoAllowedModelError` with the resolver's message. In the async path the draft goes FAILED with that reason, through the existing catch and `humanizeGenerationError`'s pass-through. In the sync path it is thrown before any model call, so no draft is created.
  - Retry re-enters `runGenerationForDraft`, so it re-runs the same initial request. `retry/route.ts` is untouched.
- **Captions.**
  - `CopyProvider.generateCaptions(brief, targets, model)` returns `{ raw, modelId }`.
  - The Anthropic provider goes through `createMessage` and reads the reply with `textOf`, never `content[0]`. Its `claude-haiku-4-5-20251001` constructor default is deleted.
  - The CLI provider calls `runClaudeCli(…, { model, label: 'copy' })`, so its timeout is the model's.
  - The OpenAI provider ignores `model` and returns `this.model` (`gpt-4o`).
  - The registry's MOCK_AI provider records through `modelCallFor`/`recordModelCall` and returns `modelId = model.arg`.
  - `writeCaptions(provider, brief, targets, model)` returns `{ fields, stamp: { model, substitutedFrom } }`.
- **Caption stamps.**
  - `captionRowsFromFields(fields, stamp)` gives an `ok` row `model` and `modelSubstitutedFrom`; a FAILED, text-less row gets `null`/`null`.
  - `saveGenerationCaptions(draftId, fields, stamp)` writes the same per row, and writes `headlineModel` / `headlineModelSubstitutedFrom` together with a validated headline only.
  - The sync create carries the same fields through the new `headlineStampFields(stamp)`.
- **Render stamps (D4).**
  - `RenderStamp` gains `model` and `modelSubstitutedFrom`.
  - `currentRenderStamp(model: ResolvedModel | null)` sets them from `model.arg` and `model.substitutedFrom`.
  - The new `draftStampFields(stamp)` maps them to `designModel` / `designModelSubstitutedFrom` (plus `promptVersion` / `fontSet`) for every Draft write: `finalizeDraftV1`, the sync create, `commitDraftRevision`'s draft write, `restoreDraftToRevision` and regenerate-design. DraftRevision rows take the stamp as-is.
  - `restoredRenderStamp` copies the revision's own `model` / `modelSubstitutedFrom`, even when the PNG is re-rendered: the HTML is still that model's (A6).
  - `rejectedRenderStamp` selects and copies them too, which is adopt's path.
- **Design.**
  - `runPathADesign(…, actor, model)` and `runPathBDesign(…, actor, model)` take a required `ResolvedModel` and pass it to both runners. `modelFor` is no longer imported in either file.
  - `runDesignAgent` takes `RunDesignAgentOptions` with `model: ResolvedModel` required. Its `claude-sonnet-4-6` default and its `deadlineMs` option are deleted, and `deadlineMs = model.timeoutMs`.
  - Every turn goes through `createMessage(…, { deadlineAt: startedAt + deadlineMs, label: 'design' })`. The final text is read with `textOf`. `AgentTruncatedError` reports the effective `max_tokens`, which includes the entry's floor.
  - The MOCK_AI branch records the model before returning.
  - `runDesignAgentCli({ model: ResolvedModel })` is required. The `timeoutMs: 300_000` literal is gone, so the timeout is the model's.
- **Refine runners** (T7 moves the route; T10 removes the string). They accept `ResolvedModel | string`, so T7 needs no change in `designAgent.ts` or `designAgentCli.ts`, neither of which is in its file list.
  - **`ResolvedModel` path:** `createMessage` with `deadlineAt`, the surface timeout, and a mock-branch record.
  - **String path:** today's direct SDK call and 300 s budget, byte-for-byte.
- **Background decision.** `internalModel('INTERNAL_BACKGROUND', pipelineMode())` in both modes:
  - CLI: `runClaudeCli({ label, model })`, so the 90 s comes from the entry, not a literal;
  - API: `createMessage` + `textOf`;
  - the `__MOCK_BG__` seam records before the mock decision;
  - the no-sentinel early return records nothing (design §7 exception).
- **`POST /api/generate/copy`** resolves `CAPTION` (team → system, as the user) and passes it on. A `NO_ALLOWED_MODEL` result is the route's existing 422 `COPY_ERROR`.
- **MCP `generate.ts`** needed no edit. It already passes `{ userId: null, teamId }` into `generateDraftForBrief`, which resolves via the team default. The scheduler (`generationRunner.ts`) is the same.

## Decisions

- **The stamp of a failed caption row is `null`, written explicitly** (not "left untouched"). A generation's failed field is stored with `text: ''`, and FR-08 says "a FAILED row with no text is left null". Leaving the column untouched would let a retry keep a previous run's stamp on a row whose text it just wiped, because retry keeps the rows' columns.
  - The settle path, where a failed regenerate keeps its text and its stamp (A7), is T7's `settleCaptionAction` and is not changed here.
- **A caption stamp's `substitutedFrom` is carried only when the provider ran the resolved model** (`reply.modelId === model.arg`). An OpenAI COPY provider stamps `gpt-4o` with `substitutedFrom: null`, so a Claude substitution is never attributed to non-Claude text (open question 1).
- **`generate/copy`'s response keeps the 012 shape exactly** (`{channel, text, status, failureReason}`). The route stores nothing, so the stamp fields are dropped from its response. This avoided changing a published contract and its deep-equality tests.
- **`resolveGenerationModels` runs before `resolveGenerationInputs`** in both paths, so a team with no allowed model fails before any lookups or model calls.
- **The refine runners' `"claude-sonnet-4-6"` default literal is kept**, for T10. `designAgentRefine.test.ts` calls `runDesignAgentRefine` with no `model`, and removing the default would change that caller's request. T10 deletes it with the string branch, when `model` becomes required. **T10 note:** `designAgent.ts` is not in T10's file list, but this literal is there, and so is `DesignAgentOptions.model?: string` in `agent/types.ts`. The literal guard will flag it.
- **Mode in unit tests is machine-dependent.** Importing `@prisma/client` loads the local `.env`; here it sets `DESIGN_PROVIDER=cli`, and CI has no `.env`. The new route and generation tests fake `teamModelPolicy.findUnique` and `userClaudeToken.findFirst`, so `resolveModel` runs for real in either mode, where `cliArg = apiId`. `background.test.ts` now pins the mode through a `config` mock, defaulting to API as before, so its CLI case is deterministic. The whole suite was run both ways.
