## Summary

- **`src/lib/models/stampLabel.ts` (new)** is pure and client-safe.
  - **`stampName(stamp)`** moved here from `pickerState.ts`, which now imports it, so the hint line and "Generated with" can't drift. A current entry's apiId or cliArg gives its display name. A retired ID (`previousApiIds`) or a foreign one shows raw.
  - **`generatedWith(stamp, substitutedFrom?)`** returns `{ text: 'Generated with Sonnet 5.5', name, substitutedTitle }`, or null when there is no stamp. `substitutedTitle` is "Substituted for <name>". A refused key (`'OPUS'`) reads by its entry's name; a refused stamp reads through `stampName`.
- **`src/components/drafts/GeneratedWith.tsx` (new):** a muted `<p class="text-ui-xs text-fg-muted">`. On a substitution it adds `<span title="Substituted for …">(substituted)</span>`, plus an sr-only copy of the title. It renders nothing without a stamp.
- **`RefinementPanel.tsx`:** new prop `designPath`. A `ModelPicker` (`id="draft-refine-model"`, `surface="REFINE"`, `context={{ designPath }}`, label "Refine model", `disabled={busy}`) sits under the instruction form.
  - The async refine body is `{ instruction, model }`, and an undefined pick is dropped (A5). The override body is unchanged.
  - **A refused pick** (`ApiError.code === 'MODEL_NOT_ALLOWED'`, a 400 before any claim) takes its row out of the log, puts the instruction back in the field, and shows the message as the picker's `error`. Any other failure keeps the existing error row.
  - **FR-22's notice** is the picker's own `Notice` slot; nothing is duplicated.
- **`CaptionPanel.tsx`:**
  - **The tail:** `<GeneratedWith>` from the row's `model` / `modelSubstitutedFrom`. It is hidden while the row is PENDING, and **for a FAILED row** (reviews/T7.md: a failed row may keep an old stamp).
  - **Then a picker,** when `ready`: `id="draft-caption-model-<channel>"`, `surface="CAPTION"`, `context={{ stamp: caption.model }}`, label "`<Instagram|LinkedIn|WhatsApp>` caption model", `disabled={locked || undo.undoing}` (the same as its Regenerate button), and `captionProviderIsClaude` from the draft.
  - **`onRegenerate(model?)`** now resolves a `RegenerateResult` (`{ ok: true } | { ok: false; modelError }`). A refusal reverts the Undo capture as before, and a model refusal also sets the picker's `error`.
- **`HeadlinePanel.tsx`:** the same pattern. `<GeneratedWith>` from `headlineModel` / `headlineModelSubstitutedFrom` is hidden while `busy`. The picker is `id="draft-headline-model"`, label "Headline model", with `context={{ stamp: headlineModel, stampNoun: 'headline' }}` → "Same model as the current headline".
- **`CaptionPanels.tsx`:**
  - **"Regenerate all"** gets a picker in the section tail, under the head: `id="draft-all-captions-model"`, label "All captions model", `context={{ stamp: regenerateStampTier(ALL_CAPTIONS, draft) }}`. That is FR-09's mixed-stamp rule: the common stamp, else null → team or system default, with no substitution.
  - **The bodies:** `RegenerateBody` is now `({ channel? } | { headline: true }) & { model? }`. `{}` / `{ channel }` / `{ headline: true }` stay byte-identical when no pick is made, so the strict route is never sent an extra key.
  - **`regenerate()`** turns `MODEL_NOT_ALLOWED` into `{ ok: false, modelError }` with no toast. Other failures toast as before.
  - It passes `headlineModel*` and `captionProviderIsClaude` down.
- **`page.tsx`:**
  - **Design regenerate:** a picker under the action bar, when `isPathB && ready`: `id="draft-design-model"`, `surface="DESIGN_FREEFORM"`, `context={{ stamp: draft.designModel, designPath: 'B' }}`, label "Design model", disabled like the button. The POST now sends `{ model }` as JSON, which is `{}` untouched (T13's route reads `{}` or `{ model }`). A model refusal shows on the picker and puts back the Undo snapshot the call replaced. Other failures toast as before.
  - **"Generated with"** for the design, under the post's caption line. It is hidden on a FAILED draft.
  - **The Versions sheet ("Revision History"):** each cell shows the model name in `text-ui-2xs` muted, with `title="Generated with …"` and an sr-only "Generated with". On a substitution it adds "(substituted)" with its own title.
  - `RefinementPanel` gets `designPath={isPathB ? 'B' : 'A'}`.
- **`GET /api/drafts/[id]`** (departure, additive) returns `captionProviderIsClaude` for **this draft**: `copyProviderIsClaude(draft.brief.teamId, draft.brief.copyProviderKey ?? undefined)`. That is the exact call `regenerate-copy` refuses a pick on. `DraftDetail` gains the field. The caption, headline and "Regenerate all" pickers pass it as `ModelPicker`'s override, so they hide exactly when the server would refuse a pick. This closes reviews/T13.md's NOTE (`/api/models` answers for the team default, not the brief's provider).
- **`listCommittedRevisions`** (departure, additive) also selects `modelSubstitutedFrom`, so the Versions sheet can show "(substituted)". The revisions route spreads rows, so it needs no edit.

**No new settle logic (015, L25).** Every control still posts, then awaits the same refetch it did before. The picker only adds `model` to the body, and the refusal branches run before anything is claimed.

## AC-29 / AC-31 → DOM map (for T18)

Every picker is a `<select>`, so it has role `combobox`. The option values are `ModelKey`s (`HAIKU` / `SONNET` / `OPUS`), and the option text is `<name> · <tier> (<speed>)`. The hint is `#<id>-hint`, which the select's `aria-describedby` points at. A refusal is the Select's field error (`#<id>-error`, with `aria-invalid="true"`). Pickers render only once `/api/models` has loaded, and only when the draft is EXPORTED or PUBLISHED. Use `exact: true` on names, because "Instagram caption model" contains "caption model".

## Decisions

- **The caption-provider mismatch uses the preferred approach** (a per-draft field on the draft GET), not just the 400 fallback. Both are in place: if the two ever disagree (a provider changed between polls), the server's `MODEL_NOT_ALLOWED` lands on the firing picker. A picker that is already hidden has no visible error, but then its pick could not have been sent.
- **The "Regenerate all" label is "All captions model".** FR-18 asks for a unique, surface-specific suffix where pickers share a screen, and plain "Caption model" would be a substring of all three channel names. Its stamp hint reads "Same model as the current caption" (`StampNoun` has no plural). That is accurate, because a stamp tier exists only when all three rows agree.
- **The design picker shows only when `isPathB && ready`,** matching where a regenerate can actually run. The design "Generated with" line stays visible during a regenerate, because the stamp is still the current design's until the new revision lands.
- **The Versions cell shows the name, not the sentence.** The cells are narrow (`grid-cols-4`, a 72 px frame). The sentence is in the `title` and the sr-only text.
- **The lint fix lists the setters as `useCallback` deps** (`[setModel, setModelError]`) in `CaptionPanel`. The React Compiler inferred `setModelError` as a dependency there, but not in the sibling panels.
