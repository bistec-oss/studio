## The literal guard (FR-15)

- **Pattern 1, a model ID:** `/claude-(?:haiku|sonnet|opus|fable|mythos)[\w.-]*/i`. This is spec FR-15's regex. A family name must follow `claude-` directly, which is what keeps `claude-token`, `claude-html`, `claude-cli` and `claude-guide(-tab)` clean.
- **Pattern 2, a bare alias:** `/(['"`])(haiku|sonnet|opus|fable|mythos)\1/gi`, matching a whole quoted string, with **ALL-CAPS matches exempt.**
  - The exemption exists because `'HAIKU'` / `'SONNET'` / `'OPUS'` are catalogue **keys** (the `ModelKey` union and the Prisma enum). Keys are the sanctioned way to name a choice outside the catalogue, and they never reach a boundary.
  - `'haiku'`, `"Opus"` and `` `Haiku` `` (spec AC-11's three plants) are flagged.
  - Prose such as `'Opus requires a personal token'` is not a whole-string alias, so it passes.
  - `mythos` is added to the spec's bare list, for symmetry with pattern 1.
- **What is skipped:** lines starting `//`, `/*` or `*`, and only `src/lib/models/catalogue.ts`. A trailing comment on a code line is scanned with the code.
- **Result on `src/`: zero violations, and nothing is allow-listed.** T6–T9 had already moved every literal, and T10 deleted the last ones (`config.ts`'s three tables and `designAgent.ts`'s refine default).
- **The self-test** has two halves:
  - it flags 7 planted forms, including a full ID inside an object, a provider-prefixed ID and an alias followed by a trailing comment;
  - it does not flag the four non-model `claude-` strings, the ALL-CAPS keys, prose, identifiers or the three comment forms.

  A further case proves the allow-list is not vacuous: the catalogue itself contains literals.

## Decisions

- **AC-12's call sites.**
  - **Surfaces that resolve inside their entry point** are called through it:
    - the assistants: `enhancePostBrief` for `ASSISTANT_BRIEFING`, `draftBrandVoice` for `ASSISTANT_BRANDKIT`;
    - the internal surfaces: `generateBackgroundForBrief`, `verifyRefine` with an `add` instruction, and `validateClaudeToken`.
  - **CAPTION, DESIGN_TEMPLATE, DESIGN_FREEFORM and REFINE** resolve one level up, in `runGenerationForDraft` / `generateDraftForBrief` / the refine route. The test calls the real `resolveModel` exactly as that caller does (`userId`, `teamId`, `designPath: 'B'`), then the real boundary-facing function:
    - the CLI or Anthropic copy provider;
    - `runDesignAgentCli` / `runDesignAgent`;
    - `runDesignAgentCliRefine` / `runDesignAgentRefine`.

    The runners' own resolution wiring is already pinned by `captionWriters`, `renderStamps` and `draftActionModels`. Driving the whole generation here would mock most of Prisma for no extra boundary coverage.

- **Expected values are computed from the catalogue** (`tableDefault`, `entryFor(...).cliArg/apiId`, `surfaces[surface].timeoutMs`), never restated. Case (b) also asserts the literal outcome: Opus everywhere eligible, and Haiku for `DESIGN_TEMPLATE` and the three internal surfaces.
- **(c) for `INTERNAL_TOKEN_PING`:** the ping is CLI-only by design (`userToken.ts`: API mode stores the token unvalidated). That case asserts `{ ok: true, skipped: true }`, no SDK call and no record.
- **(d)** is run in both modes from a stored `TeamModelPolicy` row (`source: 'team'`). One extra case shows that the team default beats `CLAUDE_CLI_MODEL`.
- **(e) is read from the armed timers.** `setTimeout` is spied with pass-through, and `Date.now` is frozen. The reason is that `createMessage` arms `deadlineAt − now` in the design loops, and only a frozen clock makes that exactly the surface timeout. The CLI kill timer and the SDK abort timer are both `setTimeout`.
- **The mode is pinned through the `config` mock, and `MOCK_AI` is forced off.** This makes the file mode-independent: it passes the same with the local `.env` (`DESIGN_PROVIDER=cli`) and with `DESIGN_PROVIDER=claude-html`. Prisma fakes only `teamModelPolicy.findUnique` and `userClaudeToken.findFirst` (no personal token, so the tier is `team` in CLI mode).
- **`ClaudeCliOptions.timeoutMs` is kept as an explicit override.** It is design §6's interface, and the T5 case "an explicit timeoutMs still wins" stays. No `src/` caller passes it any more.
