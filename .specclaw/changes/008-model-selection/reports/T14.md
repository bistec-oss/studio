## Summary

- **`src/lib/models/pickerState.ts` (new)** is pure and client-safe. It imports the catalogue, the resolver and API types only. Every answer comes from `decideModel` / `effectiveSet`; it adds no rule of its own.
  - `PickerModels` is the slice of `ModelsView` a picker reads. `PickerContext` is `{ stamp?, designPath?, stampNoun? }`.
  - **`pickerOptions(surface, models)`** returns the effective set for this user and surface, cheapest first, as `{ value: ModelKey, label: '<displayName> · <tier>', speed }`. With the gate applying, the gated entry is absent.
  - **`preselection(surface, models, context)`** is `decideModel` with no `requested`, so it is the model the server runs when the picker is left alone.
  - **`hintText(surface, resolved, context)`** gives FR-18's strings:
    - a refused stamp names itself: "<name> is no longer available on this team — using <name>". A current ID shows its display name; a retired or foreign one (`claude-sonnet-4-6`, `gpt-4o`) shows the raw ID;
    - otherwise it goes by source: "Same model as the current <caption | headline | design>", "Team default", "Default", or "Default (the team's choice isn't available)".
  - **`gatedHint(surface, models)`** is FR-22's gated-state hint: "Opus requires a personal Claude token on this team — connect one in Settings". It is computed as `effectiveSet` with the switch off minus `effectiveSet` as is, so the gate rule stays the resolver's. It returns null when nothing was left out, for example on template fill or when Opus isn't allowed.
  - **`teamTokenNotice(models, key)`** is true only in CLI mode, for a `personalTokenGated` key, on `credential: 'team'`. `TEAM_TOKEN_NOTICE` holds FR-22's text.
  - **`reportedValue(chosen, preselected)`** is the A5 send rule: choosing the pre-selected model reports `undefined`.
  - **`pickerState(surface, models, context, captionProviderIsClaude?)`** returns everything the component renders: `hidden`, `single` or `select`, with the options, the pre-selection, the hint and the gated hint.
  - **`isStalePick(state, value)`** (review NOTE 1) is true when a pick is defined but no longer offered. That happens when an admin unticked it, the gate switched on, the design path moved to template fill, or the picker is now hidden.
- **`src/lib/hooks/useModels.ts` (new)** is React Query over `GET /api/models`. It uses key `MODELS_QUERY_KEY = ['models']`, the key `ModelsCard` invalidates on save, with `staleTime` 60 s (design §9).
- **`src/components/ui/ModelPicker.tsx` (new)** wraps `Select`, which carries the `FieldLabel`, then adds the hint line (`text-ui-xs text-fg-muted`) and `Notice tone="warning" role="status"`.
  - It renders nothing until the view loads, and nothing for `hidden`.
  - It renders plain text "`<label>: <name>`" for `single`. With the default label that is "Model: Haiku 4.5".
  - The select shows `value` unless the pick is stale; a stale pick shows the pre-selection. `onChange` reports through `reportedValue`.
  - **A stale pick is reset:** an effect calls `onChange(undefined)` once per stale value. A ref remembers the value it last reset, and is cleared once the pick is no longer stale. So a caller that ignores the reset is not called in a loop, and a later stale pick of the same key still resets.
- **`src/components/ui/Select.tsx` (additive, review NOTE 2).** When `error` is set and the select has an id:
  - the error paragraph gets the id `<id>-error`;
  - that id is appended to the caller's `aria-describedby`;
  - the select gets `aria-invalid="true"`.

  Without an error, the markup is unchanged. None of the 15 existing `Select` callers passes `error`, so only the picker sees the difference.

## How T15, T16 and T17 use it

```tsx
import { ModelPicker } from '@/components/ui/ModelPicker'

const [model, setModel] = useState<ModelKey | undefined>(undefined)
<ModelPicker surface="REFINE" context={{ designPath }} value={model} onChange={setModel}
             label="Model" disabled={pending} />
// on submit: body = { instruction, ...(model ? { model } : {}) }
```

- **Props:**
  - `surface`, `value`, `onChange` and `label`;
  - `context` = `{ stamp?, designPath?, stampNoun? }`;
  - `disabled`;
  - `captionProviderIsClaude?`, the T13 NOTE 1 override: pass a draft-specific answer when the caller knows the brief's own provider;
  - `note?`, an extra hint line;
  - `error?`, the server's 400 `MODEL_NOT_ALLOWED` message, announced with the field;
  - `id` and `className`.
- **`onChange` must be a state setter or something like one.** The picker calls `onChange(undefined)` by itself when the pick stops being offered.
- **T15 (wizard Review):**
  - "Caption model" uses `surface="CAPTION"`. "Design model" uses `DESIGN_TEMPLATE` or `DESIGN_FREEFORM` by the chosen path.
  - When the path changes to template fill, a picked Opus becomes stale, and the picker resets it to `undefined` by itself. T15 only adds the reason as `note` ("Opus 5.5 isn't available for template fill"). To know when to show it, check `pickerOptions(newSurface, models)` (with `useModels().data`) at the moment the path changes.
  - The Review summary rows can read `pickerState(...).preselected.entry.displayName`, or the picked entry's name.
- **T16 (draft page):**
  - The refine box takes `context={{ designPath }}`.
  - Each caption panel takes `context={{ stamp: row.model }}`. The headline takes `context={{ stamp: headlineModel, stampNoun: 'headline' }}`.
  - "Regenerate all" takes `context={{ stamp: regenerateStampTier(targets, draft) }}`.
  - The design regenerate takes `context={{ stamp: designModel }}`.
  - Give each picker its own label ("Instagram caption model", …).
  - Pass a 400's message back through `error`.
- **T17 (chat headers):** `surface="ASSISTANT_BRIEFING"` or `"ASSISTANT_BRANDKIT"`, with no context. Send `model` on each turn while it is defined. The team-token notice comes from the picker itself.

## Decisions

- **The speed is rendered as "`<name> · <tier> (<speed>)`".** A native `<option>` can't hold separate secondary text. `pickerOptions` keeps `label` and `speed` apart, so a later custom listbox can style them separately. E2E can select by value (the `ModelKey`).
- **Choosing the pre-selected model again reports `undefined`** (A5). The server then resolves the same default, and a later team-default change still reaches the picker.
- **The pre-selection hint is dropped once the user has picked.** It describes the default, not the pick. The gated hint and the caller's `note` stay.
- **The gated hint is derived** from two `effectiveSet` calls (with the switch off and as is), so it can't disagree with the resolver's gate rule.
- **The substitution message applies when the context's stamp is the refused value.** That includes a retired ID that maps to its family, which shows the raw ID. A refused team or env default shows the source string. FR-18 lists the substitution text under the stamp ("<stamped name>").
- **The picker resets a stale pick itself** (review NOTE 1), so no caller can send a key the server would refuse.
  - The decision is pure (`isStalePick`) and unit-tested.
  - The effect itself can't run under `renderToStaticMarkup`, and the repo has no DOM test renderer. It is covered by the helper's tests and by the T18 E2E.
- **The AC-26 seed moved from 8014 to 8015** (review NOTE 3). 8014's 20 draws had no hidden case. 8015 is the first seed after it whose draws cover every source tier and the hidden branch, and a test now asserts that coverage.
- **Hidden also covers `NO_ALLOWED_MODEL`** and the loading or error state. In each case nothing can be chosen, and the server's 422 explains a run that fails.
- **`ModelsCard` is untouched.** It keeps its own `useQuery` on the same key, and its invalidation reaches every picker.
- **`ModelPicker` is not added to `src/components/ui/index.ts`** (not in the file list). Callers import it from `@/components/ui/ModelPicker`.
