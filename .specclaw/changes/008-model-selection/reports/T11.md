## Summary

- **`src/components/team/ModelsCard.tsx`** (new), FR-14:
  - `<section aria-labelledby>` named by its `SectionHead numeral="v." title="Models"` h2, then the team page's `BLOCK`.
  - **Data:** two React Query reads:
    - `['team', 'model-policy']` → `GET /api/team/model-policy`;
    - `['models']` → `GET /api/models`. This supplies the catalogue rows (display name, computed tier, speed, eligible surfaces), plus `mode` and `envDefault` for the "System default (…)" names.
  - **Load and error states:** "Loading…" until both reads resolve; `QueryError` with Retry if either fails.
  - **The form** (`ModelsForm`) is re-keyed on `policyQuery.dataUpdatedAt`. After a save, the refetched policy resets it to what the server holds, with no effect-driven `setState`.
  - **Save:** `PUT` with `policyBody(form)`. On success: a toast "Models saved", then invalidate `['team', 'model-policy']` and `['models']`. On failure: the server's message inline in `Notice tone="error" role="alert"`.
  - **Primitives:** `SectionHead`, `FieldLabel`, `Select`, `Notice`, `Button` (`variant="ink"`, the inline-form submit per DESIGN_SYSTEM §8.2, so `/team` keeps at most one accent primary), `StatusChip` (the "New" chip) and `QueryError`.
  - **Styling:** checkboxes use the existing `PublishDialog` treatment (`h-4 w-4 accent-accent` + `FOCUS`). There is no raw palette colour, and `uiTokenGuard` passes unchanged.
- **`src/lib/models/policyForm.ts`** (new, pure, client-safe). It holds the form's logic, so the component only renders:
  - `formFromPolicy`: reads the GET in catalogue order. A default outside the allowed list reads as `null`.
  - `toggleAllowed`: unticking also resets every default naming that model to `null` (the system default).
  - `systemDefaultName`: runs **`decideModel` itself** with the ticked set, no team defaults, `credential: 'n/a'`, and the view's `mode` and `envDefault`. The label therefore follows the server's tiers 4–5: `CLAUDE_CLI_MODEL` in CLI mode where it is eligible, then the table default, then the cheapest ticked model. It returns `null` when nothing ticked can run the surface.
  - `defaultOptions`: "System default (<name>)" (or "System default (none allowed)"), then each ticked, eligible model.
  - `policyBody`: the strict PUT body. Every surface is named; `null` = system default.
- **`tests/unit/modelPolicyForm.test.ts`** (new, 11 tests). It covers the helpers above. Two cases also tie the helpers to `validatePolicy`:
  - the untick-Opus body is valid;
  - the Opus-only body yields "Template fill needs Haiku or Sonnet allowed".
- **`src/app/(app)/team/page.tsx`:** imports `ModelsCard` and renders `<ModelsCard numeral="v." />` after `<ApiKeysCard numeral="iv." />`. It sits inside the page's existing `isTeamAdmin` gate (non-admins get the `GateNotice`, as for every other `/team` section). Both APIs are also gated server-side (`withTeamAdmin` / `withTeamAuth`).

## Decisions

- **Unticking a model resets the defaults that named it.** A `Select` can't show a value it doesn't offer, and the alternative is a stale value that only the server's rule-4 400 would reveal. The reset is visible: the select switches to "System default (…)". Re-ticking does not restore the old choice.
- **"System default (<name>)" names what the surface would actually run with no team default,** given the boxes ticked right now. It is computed by `decideModel`, so it includes `CLAUDE_CLI_MODEL` in CLI mode and falls back to the cheapest ticked model when the table default is unticked. It ignores the Opus gate (`credential: 'n/a'`), because the label describes the team, not a particular credential.
- **Refine's system default is named for Path B (Sonnet 5.5).** Path A drafts refine on Haiku (A8), but FR-14's label has one name per surface, so the label is not split. A later copy pass could add "(Haiku on template drafts)".
- **The section waits for both reads.** The tiers, speeds and eligibility come from `GET /api/models`, the picker view FR-13 defines, rather than from importing the catalogue's prices client-side.
- **Save is `variant="ink"`,** the inline-form submit (§8.2). The channel rows' Save and the token card's Connect use the same treatment.
- **Hidden from editors through the page's gate,** consistent with the other `/team` sections. `ModelsCard` carries no gate of its own, as `ApiKeysCard` and `TeamClaudeTokenCard` carry none.
