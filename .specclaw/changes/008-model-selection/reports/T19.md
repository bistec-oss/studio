- **Every number and name comes from the reports or the code.** The catalogue IDs and prices, the migration name, the down script's `DELETE`, the boot error text, the log formats, the picker labels and the hint strings were each checked against `src/` (see Verification). The §Y case count (20) was counted in the test file.
- **The CI result for `b36be415` is stated as "in progress, check it".** Run 38354472914 was still running while T19 was written. The docs don't claim wave 2 is green on CI.
- **Rollback wording differs from 012's on purpose.** 012 had an ordering hazard (the old image can't read post-012 drafts). 008 has none: the previous image ignores every 008 column, so going back needs no SQL. The down script is described as a destructive full removal, run with both 008 containers stopped.
- **`.env.example` is not touched.** FR-23 lists it, but T3 already re-documented `CLAUDE_CLI_MODEL` there, and it is not in T19's file list.
- **Two small findings went to "Still open after 008",** not fixed (no `src/` edits in a docs task): `src/mcp/tools/generate.ts` still has a comment about "per-path models", and the axe rule list is now copied into two E2E files.
