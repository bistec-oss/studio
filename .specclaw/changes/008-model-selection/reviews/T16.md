## Findings

### [NOTE] src/app/api/drafts/[id]/route.ts:157 — Correctness / cost

`copyProviderIsClaude(draft.brief.teamId, draft.brief.copyProviderKey ?? undefined)` has the same arguments as regenerate-copy, so the picker hides exactly when the server would refuse a pick. It is team-scoped through `findCopyProviderRecord(teamId, key)`, and it returns only a boolean, so nothing leaks. It runs on every GET, including the 4 s poll, and for drafts that are not `ready` (where no picker renders). That is one extra indexed provider lookup per poll. This is acceptable, but it could be skipped while `status` is not EXPORTED/PUBLISHED. Optional.

### [NOTE] RefinementPanel.tsx:189, page.tsx:215, CaptionPanel/HeadlinePanel/CaptionPanels — Test quality

Nothing unit-tests the refused-pick (400 MODEL_NOT_ALLOWED) restore paths. Those are the refine instruction and log row, the design Undo snapshot, the caption, headline and all-captions reverts. Reading the code, they are correct:

- Refine removes the message, restores the input, clears `resolutionRef`, and never arms settle, so there is no stuck "Applying…".
- Design restores `previousUndo`, or clears it if there was none.
- The caption and headline panels revert and show the message on the picker.

AC-29 and AC-31 at T18 should cover this in E2E. Make sure T18 includes a refused-pick case for at least refine and design.

### [NOTE] src/components/drafts/GeneratedWith.tsx / stampLabel.ts — Test quality

`generatedWith` and `stampName` are well covered (current, retired, foreign and null stamps; a substitution from a key and from a stamp). The "hidden for FAILED caption rows" rule, the `!pending` rule and the `!isFailed` rule live only in JSX and have no unit test. T18 should assert them.

### [NOTE] RefinementPanel.tsx:187 — A5

`JSON.stringify({ instruction, model })` drops an undefined `model`, so an untouched picker sends the same body as before. The design regenerate now sends `{}` where it used to send no body. The route reads an empty or missing body as `{}` and `parseRegenerateDesignBody` accepts `{}` (`regenerateDesignSchema`), so it is harmless. Caption bodies `{}`, `{channel}` and `{headline:true}` are unchanged when the pick is undefined.
