## Findings

### NOTE - `src/app/api/drafts/[id]/regenerate-copy/route.ts` (loadDraftCaptions now before resolve)

`const loaded = await loadDraftCaptions(draft.id)` runs before the resolution that can 422. For a legacy draft this materializes caption rows even when the request is then refused. The report states this is idempotent and the same write any GET makes; accepted, no action.

### NOTE - `src/lib/captions/actionTargets.ts` (settleCaptionRow, kept-stamp edge)

A row whose text was cleared by hand and whose regenerate then fails becomes FAILED with `text = ''` but keeps its old `model`. Declared in the report and consistent with FR-08 "left unchanged". Consider a one-line note in the stamp docs so the wave 2 UI does not show a model next to an empty FAILED row (hide the stamp when `status === 'FAILED'`).

### NOTE - `src/lib/drafts/refineVerify.ts` (callVerifierModel)

`new Anthropic({ ..., timeout: model.timeoutMs })` duplicates the bound `createMessage` already applies from the same entry. Harmless belt and braces; T10 may drop the client option.
