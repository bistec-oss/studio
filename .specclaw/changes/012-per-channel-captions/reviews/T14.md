## Quality

### [NOTE] `title="Copy"` is matched only in one spelling

**Problem:** `title='Copy'` or `title={'Copy'}` would pass the guard, and so would a restored `"Copy"` heading built from a variable. Case is also exact, so `Writing The Copy` or `writing the copy` escape.
**Fix:** optional. Match `/title=\{?["']Copy["']/`, or leave it, since the E2E AC-25 heading check backs it up. Not worth blocking.

### [NOTE] Strings split across a template expression or `{' '}` escape

**Problem:** whitespace collapsing handles line breaks and `&amp;` handles the entity, but `Writing the{' '}copy` or `Writing the ${x}` would not be caught. Other entities (`&nbsp;`, `&#38;`) are also not decoded.
**Fix:** none needed now. The guard is a regression net for the known strings, not a general linter. Worth a comment line saying so if it grows.

### [NOTE] Short needles can over-match

**Problem:** "Post copy" and "Writing the copy" are plain substrings, so a future "Post copyright notice" or a comment containing the phrase would fail the guard. It scans comments as well as UI text. Nothing matches today.
**Fix:** none required; if it ever fires wrongly, anchor the needle with `\b`.

### Dead code

None. `relative`, `join` and `resolve` are all used. The self-test samples mirror the list one to one, and each one-match assertion (`toHaveLength(1)`) would also catch an accidental overlap between needles.
