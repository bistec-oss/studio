# 012 T5 report: the writers, the mock caption seam, and the headline in the design prompts

**Status:** built.

## Changes

- **`captions/generate.ts` (new):** `writeCaptions(provider, input, targets)` calls the provider, extracts the reply and returns `CaptionFields`. It also holds `GENERATION_TARGETS`, `HeadlineMissingError` (whose message is the FR-09 sentence) and `requireHeadline`.
  - **Logging:** a version line on every call. `discarded` is clipped to 500 characters and JSON-quoted, so it can't forge a line. A whole-reply rejection is logged and every target becomes a failed field.
  - A provider error propagates.
- **`CopyProvider.generateCaptions(brief, targets)`** returns the raw reply. Anthropic and OpenAI use `max_tokens: CAPTION_MAX_TOKENS`. `buildCopyPrompt` is deleted.
- **Mock (`testHooks.buildMockCaptionReply`, returned by the registry's MOCK_AI provider):**
  - a raw reply: preamble, then a fenced JSON object with only the requested keys, then a trailer;
  - WhatsApp contains `**`, which normalises to `*`;
  - the four `__DROP_CAPTION_*__` sentinels act only on all-channel replies;
  - the output is deterministic.
- **`prompts/shared.onImageHeadline`:** `UNTRUSTED_CONTENT_GUARD`, a label, then `fenceUntrusted(text)`. Whitespace is collapsed and the text is capped at `HEADLINE_MAX` here.
  - Path B, Path A and the background decision use it. Path A gains the supporting-text rule (topic and description only; invent no facts).
  - `PROMPT_VERSION` is `2026-10-11.1`.
- **Generation flow:**
  - **async:** `createPendingDraft` creates 3 PENDING rows in the same write. Then `writeCaptions`, `saveGenerationCaptions`, `requireHeadline`, the design from the headline, and finalize. The catch marks the draft FAILED and also fails any row still PENDING;
  - **sync:** `requireHeadline` throws before any design is paid for or any draft created. The draft is then created with its headline, 3 rows and revision 1;
  - **retry:** one update sets IN_PROGRESS, resets the rows to PENDING, and fills missing rows with `createMany skipDuplicates`;
  - **regenerate-design:** uses `designHeadline` and logs the Topic fallback.
