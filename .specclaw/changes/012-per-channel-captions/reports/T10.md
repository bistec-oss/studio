### AC-23: how the scripts and the rollback are run

- **The backfill and report** are run from inside the test with `spawnSync('npm run captions:backfill' | 'npm run captions:report')`. The child env is `{ ...process.env, ...<.env.test parsed>, DATABASE_URL: <the .env.test URL> }`, i.e. what `dotenv -o -e .env.test --` gives.
  - **Why `-o` semantics, not plain `dotenv -e .env.test`:** the Playwright runner's own environment is not clean. Prisma's client loads `.env` into it (see the `helpers/db.ts` header), and `test:e2e:mock` sets `MOCK_AI=true`. Neither dotenv-cli without `-o` nor the scripts' `--env-file` overrides a variable already set. The first targeted run proved it: the child inherited `DESIGN_PROVIDER=cli` from the dev `.env` and `MOCK_AI=true` from the runner, and `src/lib/env.ts` refused to boot ("MOCK_AI is incompatible with DESIGN_PROVIDER=cli"). Nothing was written. With `.env.test` winning, it boots on the test config.
  - **A guard:** `testDbUrl()` throws unless the URL's database name ends in `_test`, so the scripts can never be pointed at the dev DB.
  - **How I checked the target:** (1) without touching any DB, `npx dotenv -e .env.test -- npx tsx --env-file=.env -e '…'` from my shell (no `DATABASE_URL` set) resolves `/bistec_studio_test`, while `npx tsx --env-file=.env` alone resolves `/bistec_studio` (dev). So `dotenv -e .env.test -- npm run captions:*` does win over `--env-file`, as long as the variable isn't already in the parent env. (2) In TC-CAP-12 the run's effect is asserted in the test DB itself: both drafts gain `captionMigration` and 3 rows. (3) A manual `npx dotenv -e .env.test -- npm run captions:report` / `captions:backfill` afterwards printed `report: 0 draft(s) to review` and `backfill: 0 drafts — …`. The dev DB has none of the 012 columns, so a run against it would have failed with P2022 (T4's incident); it didn't.
- **The rollback, on a scratch DB.** `CREATE DATABASE … TEMPLATE bistec_studio_test` is refused while other sessions hold the source, and the running test server always does. A `pg_dump | psql` copy works with live sessions, but it needs the Postgres client tools (docker exec locally), which CI's service container doesn't give the runner. So I chose: `CREATE DATABASE bistec_studio_test_012_rollback` (dropped first if a previous attempt left it), then `npx prisma migrate deploy` against it, which builds the identical schema from the same 31 migrations as the test DB (so `copyText` is nullable, after migration 3); then seed, through a PrismaClient on the scratch URL, one team, user and brief and the four shapes the file must handle:
  - a native draft with IG `IG text` → expects `IG text`;
  - a native draft with IG `''` and LI `Only LI text` → expects the LinkedIn fallback;
  - a native draft with no rows → expects `''`;
  - a legacy draft with `copyText` set → expects it unchanged.

  Then the **actual file** is applied with `npx prisma db execute --file prisma/rollback/012-per-channel-captions.down.sql --url <scratch>`. The case checks `information_schema.columns.is_nullable` for `Draft.copyText` goes `YES` → `NO`, that no row has NULL `copyText`, each row's value, and that the 5 `DraftCaption` rows remain. The scratch DB is dropped `WITH (FORCE)` in `finally`. This exercises the file's two statements on every branch of its `COALESCE`, and it needs nothing but Prisma, so it also runs in CI.

## Ripples outside the task's files

- **`package.json`:** `captions:backfill` and `captions:report` now use `tsx --env-file-if-exists=.env` instead of `--env-file=.env`.
  - **Failing case:** TC-CAP-12 would fail in CI (it runs `npm run captions:backfill`).
  - **Root cause:** T4 flagged it. CI has no `.env` file (the workflow env carries the values), and Node exits with `.env: not found` on a missing `--env-file`.
  - **Fix:** `--env-file-if-exists` (Node ≥ 22.9; the repo is on 22, locally 24.15) loads `.env` when present and carries on without it. Precedence is unchanged: a variable already in the environment still wins (checked: `FOO_X=fromenv` beats the file). Verified locally through TC-CAP-12.
