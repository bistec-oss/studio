**Status:** built.

## Modules

- **`prompts/caption.ts`** (`git mv` from `copy.ts`):
  - `buildCaptionPrompt(brief, targets)` returns `{system, user}`. The user prompt has one bullet per target, the headline first and then the channels in registry order. The length guidance comes from the registry: "At most 2,200 characters." for a hard limit, "Aim for at most 1,000." for a soft one.
  - The output protocol asks for exactly one JSON object with exactly the requested keys. `brief.channels` is ignored (A5).
  - **Exports:** `CAPTION_PROMPT_VERSION = '2026-10-11.1'` and `CAPTION_MAX_TOKENS = 8192`.
  - `buildCopyPrompt` is kept as a `@deprecated` wrapper that produces the old prompt unchanged. T5 removes it.
- **`captions/headline.ts`:**
  - `HEADLINE_MAX = 100`;
  - `validateHeadline`, with the reasons empty, over-limit, ` ``` ` and `<<<`;
  - `designHeadline(draft, brief)`, which returns `{text, fallback}` and falls back to the Topic only when the headline is null;
  - `headlineFallbackMessage(id)`, which gives the exact FR-09 line.
- **`captions/extract.ts`:** `captionReplyKeys(targets)` is shared with the prompt so the two can't drift. `extractCaptionReply(raw, targets)`:
  - a string-aware depth scanner that escapes raw control characters inside strings; an unclosed span gives `no-object`;
  - candidates are objects that hold at least one known key;
  - 0 candidates → `no-object`, 2 or more → `multiple-objects`, and keys outside the **requested** set → `unknown-keys`, with `discarded` set to the whole reply;
  - per target, in order: missing, not a string, then for a channel: normalise (CRLF, the registry normaliser, trim), empty, over the hard limit; the headline goes through `validateHeadline`.

## Departures from the spec text

1. **Trim comes after the normaliser**, so `" **** "` becomes empty. The headline removes `**` before collapsing whitespace, so `"** **"` becomes empty. The spec's order would let both through as non-empty.
2. **No logging in the pure modules.** FR-08's "logs" and AC-04's "logs the line" are T5's job: T5 logs `headlineFallbackMessage` and `discarded` clipped to 500 characters.
3. **A lone `{` in a preamble** makes an unclosed span, which fails closed with `no-object`. That is by design.
