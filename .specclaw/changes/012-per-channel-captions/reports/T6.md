# 012 T6 report: the draft API (GET, PATCH, regenerate-copy, sweep) and the base CaptionPanels

**Status:** built. `uiTokenGuard` and `designTokens` are green. No E2E, build or DB was run.

## API

- **`GET /api/drafts/[id]`:** drops `copyText` and adds `headline`, `captionMigration` and `captions` (`{channel, text, status, failureReason, needsReview, updatedAt}`, in registry order). Captions come only through `loadDraftCaptions`, after `recoverIfStuck`.
- **`PATCH`:** takes exactly `{channel, text}` or `{headline}`.
  - **400:** the spec FR-12 messages, and a legacy `{copyText}` gets "Send { channel, text } or { headline }".
  - **409:** on PUBLISHED, or while the row is PENDING. A headline edit gets 409 while REGENERATE_COPY holds the draft.
  - **Writes:** text is saved as typed, READY, with `needsReview` false. **It never writes `Draft.status`** (the TC-ASYNC-10 comment is kept).
- **`POST regenerate-copy`** (the name is kept):
  - **Body:** `{}` → three captions (never the headline, A9); `{channel}` → one; `{headline:true}` → the headline.
  - **Errors:** 400 on both keys, an unknown key, or `headline !== true`. 409 and 422 as before; 202 on success.
  - **The body must now be JSON.** An empty body gets 400 "Invalid JSON body"; the E2E suite and the UI send `{}`.

## Claim and settle

1. **`loadDraftCaptions` runs before `claimCaptionAction`** (T4 NOTE 3), and the claim gains `db` injection.
2. **The claim** sets REGENERATE_COPY (guarded) and marks the target rows PENDING in one transaction.
3. **The work:** `writeCaptions(targets)`, then `settleCaptionAction`, with each row write guarded on PENDING. The headline is written only when it was requested and is valid. A failed headline throws into `pendingActionError`.
4. **`startDraftAction` gains `onError`,** which runs before the release. A provider error settles every target row as failed. An `onError` failure is logged, and the release still happens.
5. **Pure rules (`actionTargets.ts`):**
   - **`settleCaptionRow`:** ok → READY with the new text. Failed on a row with text → READY, text kept, plus a reason (A7). Failed on an empty row → FAILED with `''`.
   - **`captionActionTargets`:** returns the targets per spec FR-19.

## Sweep

`planDraftRecovery` gains `settlePendingCaptions` (true for a stale generation, or a stale REGENERATE_COPY). `recoverIfStuck` settles rows before failing the run or clearing the claim. The heal path doesn't touch rows.
