# 012 T1 report: WHATSAPP in Channel, the per-channel registry, and publishable-only channel inputs

**Status:** built. Only the T1 files changed. `npx prisma generate` was run; no DB was touched.

## Changes

- **`schema.prisma`:** `enum Channel { INSTAGRAM LINKEDIN WHATSAPP }`.
- **New migration `20261011120000_channel_whatsapp`:** only `ALTER TYPE "Channel" ADD VALUE 'WHATSAPP';`.
- **`src/lib/channels.ts` (design §2), client-safe:** `CAPTION_CHANNELS` lists IG, LI and WA, each as `{channel, label, jsonKey, hardLimit, softLimit, publishable, brief, normalise}`.

  | Channel   | Hard limit | Soft limit | Publishable | Normaliser |
  | --------- | ---------- | ---------- | ----------- | ---------- |
  | Instagram | 2200       | none       | yes         | strip `**` |
  | LinkedIn  | 3000       | none       | yes         | strip `**` |
  | WhatsApp  | none       | 1000       | no          | `**` → `*` |
  - **Derived from the registry:** `CHANNEL_LABELS`, `CHANNEL_CAPTION_LIMITS` (hard only, renamed from `CHANNEL_COPY_LIMITS`), and `PUBLISHABLE_CHANNELS = CHANNEL_VALUES = [IG, LI]`.
  - **Helpers:** `captionSpec` and `captionLength`. `isPublishableChannel` is an exact-uppercase type guard.
  - `isChannel` is removed. `channelCopyLimit` is kept until T6.

- **`PublishError`:** `channel: Channel` and `terminal` (default false).
- **`publishDraft.ts`:** `publishers` is `Partial<Record<Channel,…>>`. A channel with no publisher throws a terminal `PublishError` saying "<Label> publishing isn't available yet. Copy the caption and post it by hand." before the export is signed.

## Validators (wording kept, list derived from `PUBLISHABLE_CHANNELS`)

- `POST /api/briefs`, `campaign/queue.ts` (zod enum), `POST /api/posts` and `POST /api/team/channels` reject WHATSAPP with the existing wording, and the listed channels are still only INSTAGRAM and LINKEDIN.
- `DELETE /api/team/channels/[channel]` keeps "Invalid channel".
- **MCP/ACP:**
  - `generatePost` now validates channels up front; it had no validation before.
  - `publishPost` throws before any lookup or Post row.
- The static manifest enums in `acp/agent.ts` and `mcp/server.ts` are unchanged (FR-17).

## Tests

- **`channels.test.ts`:**
  - every `Channel` value appears exactly once in the registry;
  - the order, keys and limits;
  - the labels and publishable list;
  - the normalisers (including `****x****` → `*x*` for WhatsApp);
  - `isPublishableChannel` rejects WHATSAPP, lowercase and unknown values;
  - `PublishError.terminal`.
- **`queueSchema.test.ts`:** WHATSAPP is rejected.
- **The tests can fail:** removing the WA entry, or duplicating a channel, fails the coverage test.
