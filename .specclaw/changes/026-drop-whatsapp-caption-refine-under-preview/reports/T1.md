# T1 report: remove WhatsApp from the caption registry

- `src/lib/channels.ts`: removed the WHATSAPP entry, `'whatsapp'` from `CaptionKey` and `whatsappBold`. No `generated` flag. `CHANNEL_LABELS` is built from the registry plus an explicit `WHATSAPP: 'WhatsApp'` (comment: old Post rows). `PUBLISHABLE_CHANNELS` is now the registry's channels (the `publishable` field was dead). The `CHANNEL_CAPTION_LIMITS` comment lost its WhatsApp mention.
- `src/lib/agent/prompts/caption.ts`: `CAPTION_PROMPT_VERSION` = `2026-10-23.1`; "two captions" comment; the soft-limit branch is gone.

- `src/lib/testHooks.ts`: WhatsApp sentinel and `**WhatsApp**` label branch removed; sentinel map is `Partial<Record<CaptionTarget, string>>` with an undefined guard in `dropped`.

- Comments only: `campaign/queue.ts`, `publish/publishDraft.ts`, `mcp/tools/{generate,publish}.ts`, `captions/requests.ts`, `components/drafts/CaptionPanels.tsx` ("three" wording).

Callers: `extract.ts:107` (targets come from the requested caption targets, registry channels via `captionReplyKeys`/parse), `extract.ts:135` (same, a WhatsApp target is not a registry channel so never requested), `resolve.ts:57` (after `isPublishableChannel`, which is now the registry set), `CaptionPanel.tsx:96` (rows come from `loadDraftCaptions`, which orders by registry, so legacy rows never reach it).
