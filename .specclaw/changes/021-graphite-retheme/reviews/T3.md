## Findings

### NOTE tests/unit/uiTokenGuard.test.ts:80 — pattern 8 false positive on a spread-0 soft shadow

`/(?<![\d.-])[1-9]\d*px[ _][1-9]\d*px[ _]0(?:px)?(?=[ _])/` reads its three groups as x, y, blur, but it can also anchor on y, blur, spread. A legitimate soft shadow `0 2px 2px 0 rgb(...)` (y=2, blur=2, spread=0) matches "2px 2px 0 " and would be flagged. It also never flags a negative-offset hard shadow (`-2px 2px 0 0`, `2px_-2px_0_0`) because of the `-` lookbehind and the `[1-9]` after the separator. Nothing in `src` hits today (grep reports 0), so this is latent only. Optional: anchor the first offset to a start or non-px-digit boundary such as `(?<![\w.-]|\dpx[ _])`, and add a `0 2px 2px 0` pass sample.
