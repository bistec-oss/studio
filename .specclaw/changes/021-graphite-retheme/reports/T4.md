## Decisions for the orchestrator

1. **The stepper keeps its step numbers, restyled as discs.** tasks.md says the Stepper "numerals go". I read that as Folio's italic accent numerals (A11). Deleting the number outright would change each step button's accessible name (`1Campaign` → `Campaign`, against FR-12) and break the AC-17 stepper stops in `surfaces.test.ts:574`, a test edit outside §11. It would also leave the mobile stepper (labels sr-only below sm) with nothing visible on steps not yet done. So the number stays, in a 22 px Graphite disc. If you want the number gone anyway, it is a one-line change plus that test edit.
2. **"Unfinished" is now `PILL_BADGE`**, as tasks.md says, so `StatusChip`'s `unfinished` status has no caller in `src/` any more. It is still in `StatusChip.tsx` and `uiPrimitives.test.ts:203`. T8 can delete it with the other unused leftovers, or keep it; I did not touch the T2 primitive.
3. **KPI labels and Review terms are sentence case**, not `EYEBROW`. FR-07 keeps small caps for nav sections, eyebrows, panel captions, aside heads and stepper labels; a KPI label and a `<dt>` are neither. Project group heads in the campaign picker and the Before / AI suggestion captions stay `EYEBROW` / `SMALL_CAPS`.
4. **Library tiles are `.surface` cards, not bezel cards.** The bezel is for page-level sections (A4); a tile is a list item. The post inside stays square (A3); the rounding is on the card.
5. **`StepHead`'s `index` prop was removed** with its numeral (an internal prop, five callers in the group).
6. **The resolved-kit source label is a `TAG`**, not `EYEBROW`: it is a descriptor beside the kit name, like the campaign kit and tone chips.
7. **Environment:** Docker was already running with `designer-postgres-1` and `designer-minio-1`. Only `bistec_studio_test` was dropped and recreated; `bistec_studio` was never touched. Nothing listened on :3000 or :3001 before I started.
8. **Line endings:** the checkout had these files as CRLF (`core.autocrlf=true`; the index is LF). The files I edited are written LF, as T3 did; `git diff` shows content changes only. Three brief files I did not change (`constants.ts`, `types.ts`, `useBriefWizard.ts`) were put back to CRLF, so they are clean.
