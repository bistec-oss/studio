## Decisions for the orchestrator

1. **The theme segments are `control-sm` squares (32 × 32), not the study's 32 × 30.** `h-[30px]` is a banned literal control height (014 FR-07, `designTokens` guard), and these are controls. The track is therefore `control-md` (38 px) tall. This is a 2 px deviation, noted in the component comment.
2. **The `<header>` element is the island, and the 80 px band is a plain `div`.** design.md §5 lists band then island without naming which is the `header`. AC-11 measures "the header" at x = 12 / y = 12 / radius 18, and the AC-09 opaque check uses `locator('header')`, so the island must be the landmark.
3. **`TeamAvatar` is exported from `TeamSwitcher.tsx`** and reused by `/choose-team`, rather than duplicated. It is not on the shared-name list. Moving it to `ui/` is cheap if wanted.
4. **Choose-team's role line comes from `/api/me`'s `teams[].role`.** A super admin sees "Team admin" on every team (the API maps super admins to `ADMIN`); the sidebar card says "Super admin". It is `aria-hidden` either way.
5. **No `data-testid` on the nub.** The tests find it as the FAB's first child span, so no `data-*` hook was added (FR-12).
6. **Environment:** Docker Desktop was not running. I started it and then **only** `designer-postgres-1` and `designer-minio-1` (not `designer-app-1` / `designer-scheduler-1`). Both are still running. Only `bistec_studio_test` was dropped or created. `bistec_studio` was never touched.
7. **Line endings:** my first scripted edits wrote CRLF. I normalised every touched file back to LF (verified, 0 CR), matching the repo.
8. **Pushing `v2` and the 62-PNG orchestrator review** (the tasks.md wave close) are the orchestrator's. Captures are in `ui-captures/021-T3/`.
