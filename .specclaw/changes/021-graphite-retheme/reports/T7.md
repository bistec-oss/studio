## Decisions for the orchestrator

1. **Admin tables sit inside a bezel card wrapping the scroll region.** The region itself keeps its classes, so the inset `SCROLL_FOCUS` outline and the `relative` containing block are exactly as before. Making the region the bezel would have drawn the inset focus outline over the 6 px tray.
2. **"Default" lost its decorative star.** `PILL_BADGE` is an `inline-block` 16 px pill, and `cn` is a plain join, so adding `inline-flex` for an icon would compete with `inline-block`. The star was `aria-hidden` and duplicated the filled "Set as default" star button beside it. The visible word "Default" is unchanged. To keep the glyph, it needs a `PILL_BADGE` variant, which is T8/primitive scope.
3. **The slot group heads stay `EYEBROW`** (group heads inside a card, like T4's campaign-picker group heads). The alternative is `SUB_HEAD`; the E2E reads only the h3 level and name.
4. **The connect guide keeps its own tab markup** with the `SegmentedToggle` track and segment classes, because the tabs carry `id` / `aria-controls` that the primitive doesn't take. Its focus is now the shared outline instead of an inset ring.
5. **`RegisterForm` and the reveal / command blocks are canvas wells**, the in-card form and code treatment from T4/T6.
6. **`italic` is removed from the group's empty-state lines.** No other screen used italic after T4–T6. The text is unchanged.
7. **The flake** (`a11y.test.ts:652`, the campaign briefing drawer) appeared once in the targeted `--retries=0` run and never again: alone, two full `a11y` passes, and the full suite with 0 flaky. It is outside T7's files. You may want to watch it in T8's final run.
8. **Environment:**
   - Only `bistec_studio_test` was dropped and recreated, twice.
   - **Server:** I killed only the two `test:e2e:serve` trees I started, after checking each command line. The first was npm-cli `run test:e2e:serve` (19260) → `cmd` (21960) → dotenv-cli (6716) → node (24176) → `next dev -p 3001` (21328) → start-server (23264) → 9312. The second was rooted at 3416 → 20852 → 6984 → 9120 → 23488 → 22908 → 13504.
   - :3000 and :3001 then had no listener. No MCP node process was touched.
9. **Line endings:** each file keeps the line endings it had on disk (most CRLF; `team/page.tsx` and `ChangePasswordCard.tsx` LF). `git diff --stat` shows content changes only.
