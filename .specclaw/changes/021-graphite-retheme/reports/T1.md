## Changes

### Tokens (`src/app/globals.css`, design.md §1, FR-01)

- `:root` and `.dark` now hold the study's values verbatim (study lines 25–99). There are 47 declarations on `:root` and 19 on `.dark`.
- **Added:** `--radius-xl: 26px`, `--space-5: 20px`, `--space-10: 40px`. **Removed:** `--space-12`.
- `--control-sm|md|lg` are 32 / 38 / 44 px (A1).
- The study's two `--font-*` lines are not copied, because next/font supplies them.
- `/* prettier-ignore */` is kept on `:root`. **I also added one on `.dark`.** I checked: without it, Prettier rewrites the three dark shadows as `0.3` / `0.5` / `0.7` / `0.8` and wraps them across lines. lint-staged runs `prettier --write` on `*.css`, so the commit would then break the study-equality test. `npx prettier --check src/app/globals.css` passes.
- The header comment is rewritten for Graphite. The two other Folio-named comments ("Folio surface classes", "Folio entrance") are reworded neutrally. The surface classes and `drop` are otherwise untouched; they are T2's.
- The four hard-offset shadow tokens (Folio's raised and overlay, in each theme) are gone, as pattern 8 requires.

### Tailwind (`tailwind.config.ts`, design.md §2, FR-02)

- Added `borderRadius['ui-xl']`, `opacity['12'] = '0.12'` and `letterSpacing.label = '0.14em'`.
- `fontFamily` is now exactly `{ sans, mono }`. `mono` gained the `ui-monospace, SFMono-Regular` fallbacks from design.md §2. `display` and `text` are removed.
- Two "Folio" comments are reworded. The colour keys are unchanged.

### Fonts (`src/app/layout.tsx`, design.md §3, FR-03)

- The Fraunces and Instrument Sans imports are deleted.

## Decisions for the orchestrator

1. **Pattern 1 has a false positive that design.md §6 did not foresee.**
   - `src/components/admin/brandkits/googleFonts.ts:11` lists `'Instrument Sans'` as one of the 100 Google Fonts a **brand kit** can choose for its generated posts. That is data, not the app's face. The plan-time dry run counted it among pattern 1's 9 hits.
   - Removing it would change the brand-kit font picker, against FR-12 and NFR-10. So pattern 1 carries one **named file exclusion** for that file only. A self-test proves the exclusion is pattern 1's alone and that the same line in any other file still fails.
   - `ui-exception:` is still not honoured. Please confirm, or rule that the font should be dropped from the list.
   - AC-05's shell grep `grep -rniE "fraunces|instrument[ _]sans|\bfolio\b" src` will print this line in T8. That AC needs the same carve-out, or the ruling above.
2. **Two test edits are outside §11** (both forced by T1 and minimal): `a11y.test.ts` `CONTROL_PX` / `OVERRIDE_PX`, and the `font-text` removals in `uiPrimitives.test.ts`. Both are explained in the table above.
3. **The `/* prettier-ignore */` on `.dark`** is an addition design.md §1 did not mention, and it is required.
4. **The checkout staged two files.** The `git checkout 7fdbe38^ --` path restore staged `public/BistecStudioLogo.png` and `src/components/Logo.tsx`, and my comment edit made `Logo.tsx` `MM`. Commit them as usual.
5. **Files I did not touch:** an untracked `.specclaw/changes/022-prod-data-and-deploy-restore/verify-report.md` appeared during the session. It is not mine.
6. **Small visible change:** the inline element editor's colour and font-size inputs now render in mono. Before, `font-text` silently overrode the caller's `font-mono`.
