## Decisions for the orchestrator

1. **The detail asides are `.surface` (paper) cards, not bezel cards, and not bare canvas.** The task says the main column gets bezel cards and the aside its blocks under `EYEBROW` heads. Bare blocks on the canvas floated beside the bezels, and A4 keeps the bezel for page-level sections. The paper card is the in-flow card of §4.1. To make them bare, drop `surface p-5` from the two `<aside>`s.
2. **Each campaign group is a bezel card**, and the projects list is one. A group is a page-level section with its own head (§8). Single-campaign groups leave the right column of a card empty at lg; I kept the two-column rows for longer groups.
3. **The kit's six sections are six stacked bezel cards** (tasks.md: "kit sections as bezel cards"). Their h3 heads stay `SUB_HEAD` (14 px), because `SectionHead level={3}` fixes the style and the heading levels are kept (FR-12); I did not touch the T2 primitive. If you want 16 px card heads there, `SectionHead` would need a style override, which is a T8/primitive question.
4. **The artifact-type label is `EYEBROW`**, not sentence case. The source text is the enum (`LOGO`, `REFERENCE_DOC`), and sentence case would need a text transform in code (a copy change).
5. **The round Send shows only its icon**, as T5's refine Send does. Every test reads it by role name, which `aria-label="Send"` gives (the visible "Send" word is not read anywhere), and `title="Send"` is added.
6. **"Brand voice" became a `FieldLabel`.** It was the one field label in the group still in small caps; FR-07 makes field labels sentence case. No test reads its style.
7. **The `SMALL_CAPS_LITERAL` removal** follows design.md §6 ("superseded by pattern 5"). Pattern 5 is strictly broader: every positive arbitrary `em` tracking, everywhere.
8. **`QueueEntryModal.tsx` is unchanged.** Everything §8 asks of it was already true after T2.
9. **Environment:**
   - Only `bistec_studio_test` was dropped and recreated.
   - **Server:** I killed only the tree I started, after checking each command line: npm `run test:e2e:serve` (15480), its `cmd.exe` (1516), dotenv-cli (23332), `cmd.exe` (19884), `next dev -p 3001` (19796) and start-server (14272, with its child 22148). Then :3000 and :3001 had no listener. No MCP node process was touched.
10. **Line endings:** each edited file keeps the line endings it had on disk. `git diff` shows content changes only.
