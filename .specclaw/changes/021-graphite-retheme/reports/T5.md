## Decisions for the orchestrator

1. **One Captions card, not one card per panel.** §8 lists "HeadlinePanel, CaptionPanels / CaptionPanel and RefinementPanel as bezel cards". I made `CaptionPanels` the card, with Headline and the three captions as ruled blocks inside it. Three reasons:
   - `captions.test.ts` finds the desk as the `<section>` holding the "Captions" h2 and its four h3s, so Headline must stay inside it.
   - Five nested or stacked trays (the study has two cards) read heavier than the study.
   - `HeadlinePanel` and `CaptionPanel` stay separable either way: the card is the container's, and their own markup did not change shape.

   If you want a card per panel, the change is in `CaptionPanels` and each panel root, with no test edits.

2. **"Revision History" stays as an `sr-only` h2.** The study has no visible heading over the versions, and FR-12 keeps the heading outline. The versions list also gains `aria-label="Versions"`, as in the study.
3. **(Overruled by the review; see Review fix.)** **The `Draft · <kit>` eyebrow is removed.** §8's page head is back link, h1 and meta, with the kit in the meta row, so the kit still shows. A7 keeps page eyebrows, but this one only carried "Draft" plus the kit, and the back link now sits where an eyebrow would. No test read it. The channel list in the meta row is now joined with " · " instead of ", ", as in the study.
4. **The refine status line has no version number** (the study's "Applied · v2"). The async path could know it, but the Override path settles before the refetch. I kept the word alone so that `getByText('Applied', { exact: true })` (settle-race, model-selection, surfaces) keeps matching without a test edit.
5. **The refine time is client-side.** `sentAt` is set when the request is sent. The log is local state and is lost on reload, as before.
6. **The Design model picker moved into the stage** (its foot, under a hairline). The action bar is now in the page head, where a full-width picker would push the grid down. The picker is the design's, like the "Generated with" line above it. Its id, label, pre-selection and disabled rule are unchanged.
7. **No `.btn-pri` nub on Publish.** It is optional in §8. Adding one needs Button padding overrides, which `cn`'s plain join cannot settle by source order.
8. **Version cells keep the date and the model name**, below the instruction. `model-selection.test.ts` reads the cell's `span[title="Generated with …"]`, and dropping the date would remove information.
9. **Environment:**
   - Only `bistec_studio_test` was dropped and recreated; `bistec_studio` was never touched. The two containers are still running.
   - **Server:** I killed only the tree I started on :3001, after checking each command line: `next/dist/server/lib/start-server.js` (6944), `next dev -p 3001` (22208), the dotenv-cli node (23164), its `cmd.exe` (18456), the npm chain (22876, 22376, 11960) and my two bash wrappers (17772, 23140). Nothing then listened on :3000 or :3001. No MCP node process was touched.
10. **Line endings:** the edited files are written LF, as in T3 and T4 (git's autocrlf warnings confirm LF). `git diff` shows content changes only.
