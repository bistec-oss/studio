### [BLOCK] src/lib/designData/composition.ts:76,98 — contract values differ from design.md's table (PORTRAIT subject)

design.md section 2's table gives a **per-size** subject: `product-showcase` PORTRAIT "the same subject in the lower 62%", `editorial-split` PORTRAIT "a photographic scene confined to the bottom 40%, fading across the 50 to 60% strip". The implementation has one `subject` per version (`subject: 'a device or object as the hero subject in the right 55%, lit with depth'`, and the "right 40%" editorial string), so `imageContractText(contract, sizes.PORTRAIT)` yields "Subject: ... in the right 55%" followed by "The top 38% of the frame, full width must be an empty, calm, dark area". That is a self-contradicting image prompt for every 4:5 hero post: the subject is sent to the side while the text band is on top. Version 1 is declared immutable (hash-pinned), so fixing it after T4 wires it costs a v2.
**Fix:** move `subject` onto `SizeContract` (design's `Contract.subject` is itself inconsistent with its own table), give each size its table string, update `imageContractText` and the pinned hash and the golden test at designData.test.ts:199-201 (which pins only the SQUARE string, so the gap went unseen). A PORTRAIT assertion is missing.

### [NOTE] tests/unit/designData.test.ts:162-170 — purity guard is import-statement-only

The regex `^\s*(import|export)\s+(type\s+)?[^;]*?from\s+['"]...` does catch the listed specifiers and `@prisma/client` runtime imports, and the files-list test stops a new file escaping it. Gaps: side-effect `import 'x'`, dynamic `import()` and `require`, relative paths to server modules (`../prisma`), and no negative test proving the regex fires on a violation (a regex that silently matched nothing would pass). The anchored `$` also misses subpaths like `@/lib/env/x`. Cheap fix: feed the matcher a synthetic violating source in one case; add a `import\(|require\(` check.

### [NOTE] src/lib/designData/*.ts — trailing `source` argument

`getArchetype`, `contractAt`, `isActiveKey`, `styleLabel`, `imageStyleOptions`, `planComposition` take `source: ArchetypeMap = archetypes`. Acceptable: it is a defaulted dependency parameter, typed (not `any`), no runtime branch, and the alternative (mocking a frozen module) is worse. Only cost is a wider public signature; keep it off any callers (comment says "tests only"; T4 wiring must not pass it). Minor: `IMAGE_STYLES` is `Object.freeze` shallow, its entries are mutable (the dataset says deep-frozen); one-line `deepFreeze` fixes it.

### [NOTE] tests/unit/evaluateRegions.test.ts:74 — dropped exact-0.12 boundary

### [NOTE] src/lib/designData/stamp.ts — refineReplacedStamp on classic
